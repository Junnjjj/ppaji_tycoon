## concept-28-quest-chips.png — 좌측 의뢰 칩

- 상단 캡슐 5개: 아이콘 + 숫자 (코인·인원·구명조끼·날씨·보석). 크림 바탕, 진갈색 테두리 알약
- **왼쪽 세로 의뢰 칩**: 아이콘 + 미니 진행바 (`12/12`·`24/30`·`3/5`·`1/3`·✓) —
  스펙 A4(진행 가시화)의 시각 답안. 상시 노출인데 지도를 거의 안 가린다
- 하단: 큰 사각 아이콘 버튼 줄
- 지도 구도가 우리 무대 구조(산비탈 테라스 + 폰툰 링)와 같다

## concept-29-build-carousel.png — 건설 카드 캐러셀 (핵심 지정)

- 상단 1줄: 날씨 + `1년 7월 2주 ☀ 맑음 12:30` + 현금 — **날짜·시각 표기가 흐르는 낮과 정합**
- 2줄: 만족도 86% · 방문객 128명 · 인기도 412 · 리포트(N 배지)
- 지도: 시설마다 **이름표** (매표소·매점·샤워실…), 수상 장비에 **`대기 3명` 태그**,
  손님 말풍선 (`좋아요!`·`재밌다!`)
- 하단 탭바 6개 (건설·시설·직원·연구·경영·메뉴) + 서브탭 (전체/편의/수상/놀이/데코)
- **카드 캐러셀**: 카드 = 스프라이트 썸네일 + 이름 + 크기(`3×1`) + 가격. 좌우 화살표

## 스타일 언어

크림/양피지 패널 · 진갈색 아웃라인 · 둥근 모서리 · 아이콘 우선 · 선택 = 노랑 ·
픽셀 아이콘. 밝은 팔레트라는 K35 불변식과 충돌하지 않는다 (크림도 밝다) —
단 재질 레시피(`--sk-*`)와 대비 14쌍은 재측정 필수.

## 채택하지 않는 것

- **6탭 하단바 구조** — 직원·연구·경영 시스템이 우리에게 없고, "상시 컨트롤 3개" 가
  검사로 강제된 불변식이다. 스타일(아이콘 사각 버튼)만 가져오고 구조는 유지
- 보석(제2 화폐) — 프리미엄 유료 모델에 IAP 화폐는 없다

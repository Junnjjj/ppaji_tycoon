# 경쟁작 참고 이미지 (설계 근거)

카이로 전환(2026-08-17) 판단의 실측 근거. 사설 설계 참고용으로만 보관한다.

| 파일 | 출처 | 무엇을 읽었나 |
|---|---|---|
| `pool-slide-story-park.jpg` | Pool Slide Story (Steam 1933980) | 타일 32×16px · 1280 화면에 40타일 · 손님 키 ≈ 타일 높이 1.5배 · 말풍선 3개 동시 · 손님 밀도 ≈ 화면 타일의 2% |
| `pool-slide-story-indoor.png` | 같은 게임 (사용자 제공) | **N×1 연립 시설**(샤워 칸마다 손님) · 유리벽 실내 · 문 1개 · 실내 바닥 별도 타일 |
| `terra-nil-boundary.jpg` | Terra Nil (Steam 1593030) | 플레이 영역 밖을 **같은 스케일 지형**으로 덮는다. 원경 그림 배경 없음 |

## 이 이미지들이 뒤집은 우리 가정

1. "배경은 뒤에 세운 벽" → 실제 게임은 그렇게 안 한다. 같은 스케일 지형으로 덮거나 스크롤
2. "손님을 많이 띄우면 붐빈다" → 카이로는 밀도 2%. **적은 손님이 무엇을 하는지 보이는 것**이 핵심
3. "시설은 1×1 단위" → N×1 연립이 카이로의 영리한 설계 (탭 절약 + 동시 이용이 보임)

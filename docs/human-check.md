# 사람 확인 목록 — 수배 축 (게이트 F부)

> **왜 이 문서가 따로 있나**
> **페이즈가 끝날 때마다 여기에 쌓는다.** 지금은 **P0~P8 전부**이고 **67항목**이다.
> 한꺼번에 돌린다.
>
> `/ppaji-phase-gate` 의 A~E 는 자동으로 돈다. **F 부만 사람이 한다** — 그리고 이 저장소는
> 「자동 통과를 사람 승인으로 보고하지 않는다」(`UX-ACCEPT-01`)가 계약이다.
> **P0~P8 이 A~E 를 전부 통과했고**(`verify:kairo` 431/431) 마지막 페이즈까지 닫혔지만,
> **전부 F 부가 ⬜ 미측정**이라 어느 것도 「완료」라고 안 쓴다.
>
> ⚠ **좌표만 재는 검사로는 못 잡는 종류가 있다.** `.kchips` 가 높이 2px 로 납작해져
> 「버튼은 44px 로 보이는데 `elementFromPoint` 는 아래를 집는」 버그(P3-C④)가 실제로 있었고,
> 코스 핸들이 화면 밖 `x=−284` 에 있는데 검사가 좌표를 직접 넣어 5건이 통과한 적도 있다(K33).
> **아래는 전부 진짜 손가락으로 한다.**

## 준비

```bash
npm run dev            # 출력된 Network URL 을 폰에서 연다
```

- 기기: **393×852 @3x** 급(아이폰 12~15 계열). 에뮬레이션 아님
- 매번 **새 판**에서 시작한다 (`메뉴 → 정보 → 설정 → 새 게임 시작`).
  ⚠ 앞선 확인의 잔해 위에서 재면 원인을 알 수 없다 (하네스 위생 규칙과 같다)
- 판정은 **✅ / ❌ / ⬜(못 해봄)** 셋. 「아마 될 것」은 ⬜ 다
- ❌ 가 나오면 **고치지 말고 적는다** — 이 문서는 재는 자리이고, 수리는 별도다

## 1. 30초 무설명 과업

계획 §8-11 의 정본 과업은 *"새 재료를 하나 구해 와서 요리를 만들어 매점에 걸어라"* 인데
**구해 오는 것(구입·수배)은 P3~P4 에 들어온다.** 지금 있는 것으로 자른 잠정판이 아래다.

- [ ] **T1 — 새 판에서 설명 없이 30초 안에: 매점에 새 메뉴를 하나 만들어 건다**
  - 합격: 30초 안에 완료 · 도중에 「어디로 가야 하지」로 멈추는 구간 **0회**
  - 관찰: `MENU` 를 몇 번 눌렀나 · `요리` 칸을 바로 찾았나 · 재료 칩에서 망설였나
  - ⚠ 실패해도 그 자체가 결과다. **어디서 멈췄는지**를 적는다
- [ ] **T2 — 잠긴 칸을 눌러 여는 방법을 알아냈나** (`?` 칸)
  - 합격: 눌렀을 때 「무엇을 하면 열리는지」가 읽히고, 그 말대로 하면 실제로 열린다
  - ⚠ 이게 이 게임의 **튜토리얼 전체**다 (카이로가 튜토리얼을 따로 안 만드는 방식)
- [ ] **T3 — 결산을 처음 봤을 때 「다음에 뭘 할까」가 정해지나**
  - 합격: 3 KPI → 처방 한 줄까지 읽고 **행동 하나를 고를 수 있다**
  - ❌ 신호: 히트맵부터 눈이 가고 숫자를 다시 위로 올려 찾는다

## 3.5 진짜 터치 — 상점과 수배 (P3 · P4)

상점은 밴드의 `상점` 칸이다. 탭 다섯 중 앞 넷은 **즉시**고 마지막 하나만 **기다린다** —
그 줄 갈림이 이 축의 전부다.

- [ ] **S1 — `상점` 칸이 열리고 탭 다섯이 전부 눌린다** (재료 · 강화품 · 화단·나무 · 보트·장비 · 맡긴다)
  - ⚠ 여기도 **칩 줄**이다 — P3-C④ 재발 감시 지점. 눌러서 실제로 탭이 바뀌는지 본다
- [ ] **S2 — 못 사는 것이 목록에서 안 사라지고 이유를 말한다**
  - 합격: `2등급부터 살 수 있습니다` · `현금이 부족합니다` 처럼 **방법까지** 읽힌다
  - ❌ 신호: 회색으로 죽어 있기만 하고 왜인지 모른다
- [ ] **S3 — 장비를 사면 현금이 줄고 그 줄이 `이미 있습니다`로 바뀐다**
- [ ] **S4 — 산 장비가 코스 편집에서 실제로 골라진다**
  - 그리고 **안 산 장비를 고르면** `아직 없는 장비입니다 — 상점에서 사세요`가 뜬다
  - ⚠ 이게 P3의 요점이다. 이전에는 아무 장비나 그냥 됐다
- [ ] **S5 — 강화품은 「어디에」를 묻고, 고르기 전에는 돈이 안 나간다**
- [ ] **C1 — `맡긴다` 탭에서 수배를 맡기면 현금이 줄고 `D-3 · 진행 중`이 뜬다**
- [ ] **C2 — 며칠 지나면 실제로 도착한다** (하루 24초 — 3일이면 약 72초)
  - 합격: 아침에 모달이 뜨고 **무엇이 들어왔는지**가 읽힌다
- [ ] **C3 — 앱을 새로고침해도 맡긴 수배가 남아 있다**
  - ⚠ 이게 「효과는 due tick 에, 연출만 아침에」의 이유다. 사라지면 2주짜리가 증발한 것이다
- [ ] **C4 — 한 아침에 모달이 셋 이상 연속으로 뜨지 않는다**
  - 합격: 최대 둘. 나머지는 **티커로 내려가고** 알림함에서 다시 열린다
  - ⚠ 이 상한이 없으면 PSS 부정 리뷰 1위인 「팝업 과다」가 된다
- [ ] **C5 — 홍보를 맡기고 완료되면 다음 주 손님이 실제로 는다**
  - 결산의 방문객으로 확인한다

- [ ] **U1 — 경영의 `개선` 목록에서 한 줄을 누르면 지도의 그 시설로 데려간다** (P5)
  - 합격: 카메라가 그 시설을 잡고 **시설 상세 시트**가 열린다. 목록에서 바로 안 올라간다
  - ⚠ 「어디에 돈을 쓸까」는 목록이, 「올린다」는 시트가 — 실행 입구가 하나여야 한다
- [ ] **U2 — 4단계로 올리려 하면 강화품이 없을 때 무엇이 필요한지 말한다**
  - 합격: `정비 부품 이(가) 필요합니다` 처럼 **이름으로** 읽힌다
  - ⚠ 그리고 그때 **현금이 안 줄어야** 한다 (원자성). 줄었으면 ❌
- [ ] **U3 — 강화품을 사서 그 시설에 붙이면 4단계로 올라간다**
  - 합격: 그 칸 위에 연출이 뜨고, 모달이 `단계 3 → 4` · `요금 from → to` 를 말한다
- [ ] **U4 — 5단계 시설을 옮겨도 5단계 그대로다** (P5 · §8-9)
  - ⚠ **이게 이번에 고친 버그다** — 예전엔 수수료를 내고 1단계로 돌아왔다
  - 반대로 **철거하면 전부 잃는 것이 맞다** (되돌리기가 이득이면 안 된다)

- [ ] **H1 — 직원 `+` 를 누르면 인원이 **안 늘고** 구인이 걸린다** (P6)
  - 합격: 토스트가 `안전요원 구인 — 10일 뒤` 처럼 말하고 인원은 그대로다
  - ⚠ 헷갈리면 ❌ 다. 「눌렀는데 아무 일도 안 났다」로 읽히면 문구를 고쳐야 한다
- [ ] **H2 — `−` 는 즉시 준다** (비대칭이 의도)
- [ ] **H3 — 며칠 뒤 사람이 실제로 온다** — 아침 모달이 `인원 2 → 3` 을 말한다
- [ ] **H4 — 구인을 걸어 둔 채로 상점에서 물건을 살 수 있다** (P6 · 별도 창구)
  - ⚠ 「사람 뽑는 동안 아무것도 못 산다」면 ❌ — 그래서 창구를 갈랐다

- [ ] **M1 — 지도에 말풍선이 **최대 셋**만 뜬다** (P7)
  - 합격: 이름 있는 손님에게만, 넷 이상 동시에 안 뜬다
- [ ] **M2 — 컵과 별이 **색을 빼고도** 구분된다**
  - 흑백 스크린샷으로 봐도 갈리면 ✅. 안 갈리면 모양을 더 벌려야 한다
- [ ] **M3 — 말풍선 단 손님을 탭하면 `목표` 화면이 열린다**
  - ⚠ **더블탭(확대)과 안 싸워야** 한다: 빠르게 두 번 누르면 확대만 되고 화면은 안 열려야 한다
  - ⚠ 손님이 걸어간 뒤 열려도 **그 손님**이어야 한다 (좌표가 아니라 id로 잡는다)
- [ ] **M4 — 더운 날 줄 선 손님에게 땀 표식이 뜬다**
- [ ] **M5 — 승급할 때 소리가 난다** (`sfx/grade-up` — 지금까지 한 번도 안 울렸다)
  - ⚠ 소리 자체가 아직 무음 구현이라면 ⬜ 로 두고 「다음 할 일」 1번과 함께 본다

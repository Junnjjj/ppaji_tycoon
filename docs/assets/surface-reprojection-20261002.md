# 원본 표면 재투영 · 2026-10-02

사용자가 코인라커·탈의실의 새 표면 재투영 결과를 수락하고 스킬화 및 조사 대상 확대를 요청했다. 기존 구간별 이미지 변형은 거절된 방식이며 재사용하지 않는다.

원본에서 벽·전면·상판 등의 그림을 추출하고 하나의 부품 배치에 붙인 뒤, 전체를 90도씩 회전하여 같은 아이소 투영으로 렌더한다. Blender/ImageGen 재생성 없이 원본의 색과 명암을 재사용한다. 원본의 입체 형상을 완전히 복원하거나 물리 조명을 재계산한 것은 아니다.

스킬: [ppaji-surface-reprojection](../../.agents/skills/ppaji-surface-reprojection/SKILL.md). 전역 Codex skills 및 에셋 작업 워크트리에도 같은 버전을 설치했다. Python 3 / Pillow / NumPy 필요.

## 적용 상태

- `6ef64e9`: 코인라커·탈의실 8방향을 메인에 적용. packed 768px WebP 및 native 192px PNG, 각 manifest 갱신. 기존 anchor/pivot/footprint 유지. 버전 파일명을 사용하여 이전 파일을 보존했다.
- 전체 100종 400방향을 비교판으로 재조사. 적용 2종, 추가 시험 12종, 구조/표면 상세 검수 필요 26종, 수정 필요 미확정으로 유지 54종, 자연 형상 유지 6종.
- 추가 시험: 오락기, 실내 자판기, 대여소, 드라이룸, 샤워실, 아이스크림, 식혜, 붕어빵, 카페2, 푸드코트, BBQ존, 평상. 메인 미적용. 붕어빵 d1 원본 선호 유지.
- 100종 전체 수정 완료나 전부 95점이라는 뜻이 아니다. 직선 검사를 통과해도 소품 누락·질감 손상·원본과 다른 비율은 보류한다.

## 검증

승인본 8개는 범용 스킬 렌더러로 RGBA 동일 재현. 저장 PNG의 주요 가시 선분 158개 통과. 일부러 휜 선을 넣은 대조군에서 14개 실패 검출. 잘못된 원본 해시·비평면 입력 거부 확인. 짧은 내부 선과 의도적 곡선까지 전부 검증한 것은 아니다.

실제 게임 HTTP 로딩 8/8 픽셀 일치. 전체 400개 이미지 manifest 해시 일치, 조사 원본 대비 392개 불변·승인본 8개만 변경. 빌드 통과, 에셋 계약 테스트 9개 통과. 전체 `npm run verify`는 시뮬레이션 기준값 실패 및 장기 봇 시간 초과가 발생해 약 12분 후 중단했다. 전체 검증 성공으로 표시하지 않는다. 시뮬레이션 코드/기준값은 수정하지 않았다.

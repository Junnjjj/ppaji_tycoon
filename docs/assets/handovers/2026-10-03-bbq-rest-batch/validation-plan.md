# BBQ존·평상 연립·그늘막 검증안

- 기존 4×3 / 4×2 / 2×2 등록·앵커·768 패킹·density4 유지. 원본 전체 이미지를 왜곡하거나 방향마다 재배치하지 않는다.
- BBQ: 별도 식탁1, 벤치2, 접시3, 화로1. 평상: 낮은 받침2와 방석4. 그늘막: 네 기둥과 처진 천, 목재 바닥. 색감·비율·원본의 정체성을 실제 크기로 비교한다.
- 닫힌 입체 모서리2회 공유, 회전 전후 변 길이 불변, 선언된 부품 접합, 잘림 검사. 천 모서리4곳은 실제 함수 높이와 기둥 상단 접촉을 별도로 검사한다. 방석은 둥근 닫힌 메시이며 천 곡선은 삼각화한다.
- 분리된 식탁/벤치/화로 또는 평상은 화면에서 겹칠 수 있다. 개별 구조가 연결되고 공간 간격이 양수인지 확인하며 전체 알파성분 수를 임의 고정하지 않는다. 떠 있는 작은 성분은 허용하지 않는다.
- 저장 이미지의 노출된 긴 목재 직선은 기울기 오차≤.04, RMS≤1.5packedpx. 바닥이 있는 그늘막은 하단 실루엣 각2선/총8선. BBQ/평상은 상단 수평 목재 경계 두 축을 검사하고 가림을 별도 기록한다. 천 곡선·방석·접시는 직선 인증 대상이 아니다.
- 원본→교체4방향 격자→선/확대→동일 배치 실게임맵을 연속 보고서로 제시한다. 미술95점/전체 선 정확성 자동 인증을 주장하지 않는다.

선 표본은 양 끝18%를 제외한다. 분리 가구의 단독 상단 경계와 합성 화면에서 실제 노출된 표본을 함께 기록한다. 합성 가시 표본 8개 이상·x폭10px 초과일 때만 선을 피팅한다. 명시적 2px 격자 MaxFilter3 외곽 팽창은 기울기0.5에서 수직3px이므로 가이드 잔차는 이를 반영하며 허용1.5px을 유지한다.

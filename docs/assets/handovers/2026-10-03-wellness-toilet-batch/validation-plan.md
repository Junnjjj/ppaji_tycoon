# 안마의자·족욕·화장실 검증안

- 기존 3×2 / 3×2 / 2×2 등록·앵커·768 패킹·density4 유지. 원본을 방향별로 뒤틀지 않고 공통 구조를 회전한다.
- 안마의자는 파란 좌판·기울어진 등받이·발받침 각3개, 금속 프레임과 양팔걸이. 족욕은 긴 벤치와 크림 테두리의 청록 수조. 화장실은 빨강/파랑 문, 청색 긴 지붕 패널과 크림 벽·파란 하부 띠·측면 환기구.
- 닫힌 부품 모서리2회 공유·회전 변 길이 불변·잘림·실제 정점 기준 선언된 접합 검사. 기울인 쿠션과 금속 프레임 접합 및 화장실 경사지붕 기둥 접촉을 확인한다.
- 분리된 의자와 벤치/수조는 양수의 공간 간격과 단독 이미지 연결성을 확인. 가려진 선을 인증했다고 표시하지 않는다. 의자 곡면은 지면 직선 대상이 아니며 의자 아래 금속 수평 받침을 따로 검사한다.
- 화장실 바닥8선, 족욕 긴 벤치/수조 경계, 의자의 노출된 수평 프레임 선: 충분한 길이일 때 기울기오차≤.04/RMS≤1.5packedpx, 짧은 선은 각도 인증 대신 픽셀 중심 기준선 잔차만 기록한다. 다리 등 실제 가림은 모델 투영과 대응해 기록한다.
- 같은 배율의 원본/교체4방향 격자와 확대·실제게임맵으로 미술을 검토한다. 원본 모든 픽셀 보존이나 미술95점 자동 인증을 주장하지 않는다.

금속 튜브 접합은 실제 중심선 최단거리≤반지름합으로 추가 검사하며 뒤 가로대 끝점은 등받이 중심선에서 계산한다. 튜브의 노출 윤곽은 투영한 원단면 지지거리와 1packedpx 세선 윤곽 팽창을 반영한다. 긴 가구 상단은 2packedpx 윤곽 팽창을 반영하며 모든 가이드 이격은 픽셀 중심 좌표로 계산한다.

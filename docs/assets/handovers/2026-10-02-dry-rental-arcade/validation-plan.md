# 선 표현 검증안 — 렌더 수정 전 기준

- 기준 원본: angle-survey-20261002/full-images. 비교 기준: dry-rental-template-20261002. 직전 paint A/B는 사용자 거절로 채택하지 않는다.
- 같은 packed 픽셀 배율(768 canvas, density4)에서 원본/기존/수정 8방향 및 확대 crop을 비교한다. 보기 좋게 개별 이미지 크기를 맞추지 않는다.
- 원본/기존 16개 노출 상단 선을 알파>160 기준으로 탐색한 ROI를 source-line-survey.json에 기록했다. ROI 선택은 길이와 직선 회귀오차만 사용했다. 원본의 기울기 오차는 복제하지 않는다.
- 측정: 어두운 선(luma<95)의 첫 연속 길이를 선 법선 방향으로 환산. 원본 2.63~4.40 packed px, 기존 1.34~1.81 px. 원본 선 중심 luma 7.8~29.9, 기존 40~46. 원본 대여소 알파 계단 평탄구간 중앙값4~6 px, 기존2 px. 드라이룸 원본은 알파 평탄구간2~3.5로 불균일하여 동일 주기라고 단정하지 않는다.

## 수정 후 사전 통과 기준

1. 모든 모델 좌표/크기/앵커/회전 명세는 동일. 팔레트 얼룩을 넣은 직전A/B 재사용 금지.
2. 새 상단선 기울기 절댓값0.50±0.04. 전체 투영 축 유지. 선 위치 회귀오차<=1.5px 허용(계단 래스터 특성).
3. 노출 외곽 어두운 선 법선폭 중앙값2.4~4.5px, 중심luma15~32. 의도된 새 외곽 2px 래스터 셀의 plateau 중앙값4px 부근(3~5px).
4. 외곽선은 진하게, 내부 분할은 약하게. 조끼 삼각분할/원통 세그먼트선 노출 금지. 내부선이 접합부를 검은 덩어리로 만드는지 확대 육안 검수.
5. 저장 알파 경계는 기존 대비 Chebyshev 거리3packed px 이내. 이전처럼 알파 완전일치를 요구하지 않는다. 이번 목적에 윤곽 래스터 변경이 포함된다. crop/예약/앵커는 그대로.
6. 8방향 불투명 영역 연결, 캔버스 잘림, 거울 두 개/드라이어 두 개/조끼 세 개/옷걸이 연결 확인. 작은 옷걸이는 별도 세밀한 래스터 허용, 원본 구조를 삭제해 점수를 맞추지 않는다.
7. 실제게임4방향 배치에서 정상크기로 확인. 원본/기존/새 결과, 선 확대ROI와 측정표를 연속 보고서에 공개한다. 미술적 유사도는 사용자 판단이며 95점 자동인증은 하지 않는다.

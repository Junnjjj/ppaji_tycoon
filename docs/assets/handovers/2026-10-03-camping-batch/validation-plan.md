# 카라반·방갈로·글램핑 검증안

- 원본의 카라반 크림 차체/남색 띠/청록문/창3/바퀴/2단 계단, 방갈로 완만한 한쪽 경사 청록 지붕/목재 벽/문/창2/화분, 글램핑 크림 아치/가로 이음선3/문/창2/데크를 고정된 한 구조로 만든다.
- 카라반은 원본보다 좁고 높게 나온 초안을 넓고 낮게 조정한다. 바퀴는4개, 고정 축2개이며 방향별 원본 모순을 공통 배치로 해석한다. 방갈로 지붕 돌출 폭과 글램핑 아치 높이를 원본 표시 크기에 맞춘다.
- 모든 면의 회전 길이 불변, 모든 닫힌 부품의 변2면 공유, 실제 정점 경계 상자로 선언 접합을 확인한다. 방갈로 기둥4개는 실제 지붕 함수와 접촉 높이를 검사한다. 카라반 바퀴4개는 실제 바닥z=0 접촉과 차체/축 접합을 확인한다. 글램핑 천막과 이음선은 같은 타원 단면의 정점인지 직접 확인한다.
- PNG 잘림·작은 분리 조각 검사, 카라반 단독 차체4장 연결성 검사. 방갈로/글램핑 바닥16선과 카라반 단독 차체의 긴 지붕 경계4선을 검사한다. 기울기 오차≤.04, RMS≤1.5packedpx, 3packedpx 윤곽 팽창을 보정한 잔차≤1.5. 둥근 모서리나 천막 곡면을 직선 통과로 계산하지 않는다.
- 원본/후보4방향을 같은 배율 격자·확대·실제 지도에서 확인한다. 게임 후보12장 픽셀/저장소 불변, 적용 뒤 HTTP 해시/RGBA 및 game provider 일치, 관련 계약 테스트를 확인한다.

표면은 원본 색감과 형태를 참고해 작성한 공통 구조이며 모든 원본 픽셀이나 숨은 내부의 복원이 아니다. 창은 불투명 반사면이다. 타원 천막은 천 물리 시뮬레이션이 아니며, 수치 검사는 모든 내부선·곡선의 미술95점 인증이 아니다.

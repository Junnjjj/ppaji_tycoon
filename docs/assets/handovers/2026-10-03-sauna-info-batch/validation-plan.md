# 사우나·찜질방·안내소 검증안

## 교체 기준
- 원본 황금색 목재, 사우나 벤치2/히터/돌/수건, 찜질방 매트3/베개3/히터3/수건함/온도계, 안내소 카운터/안내판/책자의 정체성을 유지한다.
- 구조 전체를 동일 원점에서 회전한다. 부품 이동, 카메라를 향하는 평면, 방향별 크기 변경을 금지한다.
- 실내는 고정된 벽4개를 작성하고 카메라 앞쪽 벽2개와 부착된 문/몰딩만 생략한다. 가구나 문 위치를 바꾸지 않는다. 이는 원본의 내부 단면 표시 규칙이며 완전한 외벽 렌더가 아니다.
- 기존 등록 크기, 앵커, 4배 밀도와 붕어빵 d1 예외 등 다른 에셋을 보존한다.

## 미술 검토
원본과 같은 배율의 d0–d3, 격자, 확대 선, 실제 게임 지도에서 색감·비율·실루엣·부품 누락/부유/이격을 확인한다. 첫 출력의 과밀한 나뭇결, 부푼 매트, 약한 청록 띠를 수정한다. 원본의 방향별 모순은 고정 배치로 정리하며 원본 픽셀의 완전한 복원은 주장하지 않는다.

## 수치 검사
1. 모든 선언 접합의 실제 정점 경계 상자 교차。모든 닫힌 부품의 각 변이 두 면에 공유되는지 확인. 경계 상자 검사는 정밀 메시 충돌 증명이 아니다.
2. 회전시 모든 면의 변 길이 불변. 앞쪽 벽을 생략하는 정확한 규칙, 방향마다 벽2개 노출, 문은 v1 벽과 함께 보이거나 숨김. 가구의 면/정점은 네 방향에 항상 동일.
3. 저장 PNG 잘림/작은 분리 조각 검사. 분리 가구는 단독 렌더 연결성과 공간 간격 검사.
4. 사우나/찜질방 바닥선, 사우나 단독 벤치 상판선, 안내소 단독 카운터 상판선과 안내판 가로대선: 기울기 오차≤0.04, 잔차 RMS≤1.5 packed px. 윤곽 팽창은 기존 선 마감의 3 packed px를 반영한다. 짧은 곡선과 가려진 선을 검사 통과로 계산하지 않는다.
5. 실제 게임 후보 12장/HTTP 픽셀 일치, 저장 데이터 불변, 같은 배치와 카메라 원본·교체 지도6장. 승격 뒤 HTTP 파일 해시/픽셀/게임 provider 검증과 관련 계약 테스트.

수치 PASS는 검사항목에만 해당하며 모든 내부선이나 미술95점 자동 인증이 아니다.

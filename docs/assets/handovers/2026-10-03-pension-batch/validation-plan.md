# 펜션 3종 검증안

- 원본 5×4/4×5 등록·앵커·768 캔버스·밀도4 보존.
- 한 구조에서 d0–d3 회전. 변 길이 오차 <1e-8, 닫힌 부품의 변 2회 사용.
- 선언 접합 AABB 겹침 >=0. 지붕과 지지대는 실제 높이 함수로 추가 검사.
- 저장된 바닥선 총24구간: 기울기 오차 ≤.04, RMS ≤1.5px, 윤곽선 보정 잔차 ≤1.5px. 기준을 결과에 맞춰 바꾸지 않음.
- 잘림·작은 고립 조각 없음. 창·발코니·화분·옥상 시설은 고정 배치.
- 3층 수영장에는 데크 개구부가 실제로 존재. 유리 제거 대조에서 변화가 투영된 유리 영역에 한정되고, 하늘이 비치는 난간 투명도가 보존되는지 검사.
- 원본/교체본의 동일 배율 확대 및 실제 게임4방향 맵 확인. 후보PNG 로딩12방향, 승격후WebP12방향과 실제 런타임RGBA 비교.
- 전체 내부선·원본 완전복원·미술적 95점 인증이 아님. 라운지 내부의 테이블과 의자2는 원본에 보이는 단서를 바탕으로 공통 배치를 작성.

- `sim/course/ride.ts`: 실제 손님 UID에 연결된 승선·운항·하선·낙수·복귀 상태. 수입과 사고 판정은 시뮬레이션 소유이며 렌더링이 보상이나 손님을 생성하지 않는다.

## 실제 게임 연결

- 새 판은 기존 도로·실내·자연 지형을 유지한다. 구 선착장 자리와 인접한 빈 평지 데크 두 칸이 있을 때만 같은 UID·이용/수입 기록을 유지해 `boarding_dock`으로 변환한다. 공간이 없으면 구 저장의 1×1 선착장을 유지한다. 지형을 칠하거나 이웃 시설을 밀어내지 않는다.
- 선착장 인식은 `COURSE_DOCK_IDS`를 공유한다. 코스 후보·배치 차단·패키지 수요·봇·실제 승하선이 같은 선착장을 읽는다. 통로 데이터는 미회전 로컬 좌표로 저장해 회전 시 두 번 돌지 않는다.
- 정박 중인 배도 시뮬레이션이 제공하는 물쪽 승선 위치를 사용한다. 렌더러의 독립 시간 기반 장식 운항은 제거했다. 여분 대수는 대기 선박을 같은 위치에 중복 그리지 않고 실제 출항 때 표시한다.
- 견인선은 승선·운항·하선에 같은 위치 함수를 사용한다. 급커브에서 줄의 직선 길이가 줄어 선체가 겹치던 부분은 물 안에서 최소 간격을 보정한다. 줄 길이를 강제로 고정하는 완전한 선박 충돌 물리는 아니다.
- 출항 뒤 코스나 장비를 편집·삭제해도 이미 뜬 운항은 저장한 원래 경로·장비로 끝낸다. 저장/복원도 현재 편집된 코스를 역참조하지 않는다.
- 반동 6종·낙수 9종은 원본 프로파일을 사용한다. 낙수는 진행률 35~70%, 최고 속도의 70% 이상에서만 가능하다. 물보라는 공중 이탈 시작이 아니라 착수 단계에서 발생한다. 부상 처리는 기존 사고 확률식/일일 상한을 공유하며 의무실 이동은 물에서 올라온 뒤 시작한다.
- 실제 손님이 조합 시설의 `entryTile`까지 걸어온다. 선택된 구성품 방문 경로 하나를 시설 이용 시간에 맞춰 재생하고 같은 입구로 돌아온다. 367초 전체 투어는 QA용이며 모든 손님에게 강제하지 않는다. 예약 발자국 전체가 아니라 원본 데크 칸만 걸을 수 있다.
- 물결은 대각 타일 행마다 깊이를 나눠 배·시설·사람 위에 전역 물결이 그려지던 문제를 수정했다.

## 범위의 한계

원본 인계에 미완성으로 기록된 특수 회전·블롭 물리·일부 보드 전용 손잡이 포즈를 새로 완성했다고 주장하지 않는다. 승인된 좌석·표준 포즈와 실제 운항을 연결하는 작업이다. V8에 승인된 어린이·노인 전용 체형과 대여 튜브 포즈는 아직 없다. 일반 보행의 해당 체형은 기존 표현을 유지하며, 새 기구 이용은 승인 V8 표준 포즈를 사용한다. 게임 빌드 도구의 기존 회전 UI가 두 방향인 상태에서 원본 네 방향 렌더가 존재한다는 이유만으로 네 방향 건설이 구현되었다고 표시하지 않는다.

# 분식·치킨·화로대열 전체 교체 검증안

- 분식: 둥근 주황 기와, 회색 배기 굴뚝, 목재 주문대, 빨강/노랑 음식 두 트레이, 오른쪽 목재 문. 원본 방향의 음식 수와 굴뚝 크기 차이는 공통 배치로 정리한다.
- 치킨: 주황 기와와 작은 기와 차양, 앞 왼쪽 청록 문, 앞 오른쪽 주문창, 오른쪽 청록 창. 원본에 없는 마스코트나 메뉴판을 새로 넣지 않는다.
- 화로대열: 서로 분리된 화로3개, 화로마다 다리4와 가로 받침, 금속 테두리/석쇠/숯. 1번 불꽃, 2번 소시지3, 3번 노랑 음식2로 고정해 회전한다. 원본 방향마다 달라지는 내용물 그대로를 재현하지 않는다.
- 기와는 곡선 단면을 여러 평면으로 연결한 닫힌 입체이며, 모든 부품은 공통 좌표에서 회전한다. 기둥 꼭대기는 경사지붕 실제 높이에 맞춘다. 768 패킹·density4·등록앵커·3×1 또는2×2 면적 유지.
- 닫힌 입체의 모서리2회 공유, 접합·기둥/지붕 접촉, 회전 변 길이 불변과 잘림을 검사한다. 분식/치킨은 연결알파1개, 화로대열은 화로3개의 별도알파성분을 기대한다.
- 분식/치킨 바닥실루엣 각8구간: |기울기| .46~.54, RMS≤1.5packedpx. 화로는 연속바닥이 없으므로 각 화로 금속테두리의 실제 보이는 두 축 선(총24구간)을 따로 검사한다: 기대기울기 오차≤.04, RMS≤1.5px, 평균가이드이격≤1.5px. 음식·불꽃·기와곡선은 지면 직선 검사 대상이 아니다.
- 원본/교체4방향·선검사·확대·실게임맵을 연속 표시하고, 동일 카메라와 등록으로 비교한다. 미술95점 자동 인증이나 전체 숨은 구조의 정확한 복원을 주장하지 않는다.

## 최초 검사 후 조건 수정 근거

화로는 공간상 분리되어도 투영 후 서로 가려 전체 알파가 1개로 연결된다. 하단 테두리의 알파 끝점은 아래 팬과 겹쳐 그 선 자체가 아니다. 실패 기록 first-qa-failure.json 유지. 실제 부품의 u 간격>0, 화로별 단독 렌더 연결성1, 단독 상단 윤곽24구간 및 합성 화면 노출16구간을 검사한다. 가려진8구간은 별도 기록한다. 2px 격자 MaxFilter3 윤곽 팽창은 x/y각2px라 기울기0.5에서 수직3px를 만든다. 가이드 이격은 이 명시적3px 외곽선 두께를 뺀 잔차≤1.5px로 판정하며 기울기오차 .04/RMS1.5는 유지한다.

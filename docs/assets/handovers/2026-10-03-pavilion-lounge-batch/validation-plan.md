# 정자·파라솔·선베드 열 검증안

- 기존 3×3 / 2×2 / 4×2 등록·앵커·768 패킹·density4 유지. 4방향은 하나의 구조를 회전해 생성한다.
- 정자는 검푸른 굽은 기와 지붕, 네 기둥과 두 인접 난간, 목재 바닥. 파라솔은 청록/크림 12색면, 중앙 기둥, 테이블과 의자2개. 선베드는 낮은 매트4개, 베개4개, 짧은 다리16개와 파랑/청록 교대 순서를 유지한다.
- 닫힌 메시의 모서리2회 공유, 실제 정점 기준 접합, 회전 변 길이 불변·잘림 검사. 정자 기둥은 실제 곡면 지붕 아래와 접촉, 파라솔 중앙 기둥과 천·테이블 접촉, 매트·베개 접합을 별도 확인한다.
- 선베드와 의자는 별도 가구로서 실제 간격 양수, 각 단독 이미지 연결성 확인. 합성 화면에서 가려지는 부품을 누락으로 판단하거나 가려진 선을 검증했다고 주장하지 않는다.
- 정자 바닥8선, 분리 가구는 단독/합성 노출된 목재 상단선의 기울기오차≤.04·RMS≤1.5packedpx. 명시적 2packedpx 윤곽 격자 팽창을 반영한 상단 외곽 이격잔차≤1.5px. 곡선 지붕·파라솔·매트는 지면 직선 대상이 아니다.
- 원본/교체4방향을 같은 격자에 표시하고 실제 게임 배치·축소 크기를 비교한다. 미술95점 또는 모든 내부선의 자동 인증을 주장하지 않는다.

## 초기 검사 수정 기록

first-qa-failures.json에 두 건을 보존한다. 정자 지붕은 반대 대각 마루선에서 삼각형이 능선을 가로질러 기둥 겹침이 과해졌으므로 메시 삼각분할을 능선에 맞춰 수정했다. 좁은 의자 좌판은 실제 다리 때문에 하단 알파 경계가 끊긴다. 누락된 표본 모두가 선언된 다리 투영면(1px 윤곽 여유)과 겹치는지 검사하고 기록한다. 실제 노출 표본≥8개/x폭>10px로 선을 피팅한다. 상단 경계는 표본65% 이상 요구하고 기울기오차/RMS 임계값은 유지한다.

가시 x폭≤10px인 의자 좌판은 독립 각도 피팅 인증에서 제외하며 그 사실을 결과에 표시한다. 가시 표본≥4개의 예측 선 이격과 잔차 RMS만 검사한다. 긴 선 기울기 기준을 완화해 통과시킨 것으로 표현하지 않는다.

아래 프레임에 다리가 붙는 선베드도 명시된 다리 투영으로 가려진 표본을 기록한다. 가이드 이격은 저장 픽셀 중심 (x+.5,y+.5)을 기준으로 계산한다. 최초 모서리좌표/픽셀인덱스 혼용 실패는 pixel-origin-failure.json에 보존한다.

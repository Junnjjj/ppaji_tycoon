# NPC × 시설 상호작용 — 시설 확정 후 재개

2026-09-11 사용자 결정: “시설별 상호작용은 아직 정해지지 않아서 문서화만 남기고 시설 정해지면 그때 이어서”.

**상태: `DEFERRED_UNTIL_FACILITY_DEFINED` — 의도적 보류, 실패나 완료가 아님.**
이 문서는 재개 체크리스트이며 확정된 시설 설계/런타임 계약이 아니다. 이전의 “인물 작업1~6을 한 묶음으로 진행” 제안 중 시설에 의존하는 항목은 이 결정이 우선한다. 시설 작업은 문서화만 유지하며 시설 전용 이미지 생성·접점 수정·본게임 연결은 시작하지 않는다. 별도 활성 목표에 따른 인물 자체 비례·걷기 검증이 시설 보류를 해제하지 않는다.

## 나중에 시설별로 채울 항목

미정은 `TBD`로 기록한다. “아직 미정”과 “해당 없음”을 구분하고, 수치/인원/출구를 임의로 채우지 않는다.

1. **대상과 버전:** 시설 ID, 확정된 원본/manifest 경로·버전 또는 해시, 설치 footprint·사람 대비 축척, 지원 회전.
2. **이용 방식:** 서기/착석/눕기/입수/슬라이드 등 실제 필요한 자세, 인물이 밖에서 보이는지, 동시 이용 인원. 기존 검토 맵의 정원은 참고값일 뿐이다.
3. **진입·퇴장:** 접근 타일/위치와 방향, 입구, 퇴장 방식. 별도 출구가 없으면 “입구 공유” 등 실제 규칙을 명시하고 출구를 억지로 만들지 않는다.
4. **점유와 접점:** 좌석/이용 슬롯 ID, 필요한 발·골반·몸 받침·등받이·수면 접점, 각 회전의 대응 관계. 원본 픽셀 좌표와 맵 좌표/단위를 구분한다.
5. **표시와 가림:** 인물 앞/뒤의 시설 부분, 지붕·가구·수면 마스크, 물 효과. 안 보이는 실내 인물은 만들지 않는다.
6. **상태와 점유 해제:** 예약→이동→이용→퇴장, 이용 불가/취소/시설 회전·철거 등 예외에서 슬롯을 어떻게 비울지. 확정 시 기존 게임 규칙에 맞춰 정한다.
7. **검증 범위:** 지원 회전×필요 자세×외형 조합, 무인/1명/정원, 접점·가림·동선·외형 유지·저장/성능. 최종 허용 오차와 사용자 확인 대상도 이때 기록한다.

## 재개 순서

재개 시에는 **대상 시설, 사용할 그림/모델과 설치 크기, 원하는 이용 방식**을 확인한다. 나머지 미정 항목은 해당 시설을 설계할 때 함께 채우며, 현재 테스트 수치를 확정값으로 복사하지 않는다. 시설 에셋의 외형 승인이 상호작용 확정을 뜻하지는 않는다.

1. 사용자가 확정한 시설과 이용 방식을 확인한다. **확정된 시설부터 부분 재개**하며 모든 시설의 확정을 기다릴 필요는 없다.
2. 그 시설의 위 항목을 채우고 이전 검토 수치 중 재사용 가능한 것과 무효가 된 것을 구분한다.
3. 기본 인물1종으로 실제 시설 접점·가림·지원 회전을 먼저 검증한다. 필요한 시설 전용 자세만 이때 만든다.
4. 통과한 자세에 기존 머리·옷을 재사용하고, 외형별·정원별 회귀 검사를 한다.
5. 기존 게임의 예약/길찾기/저장 흐름에 연결해 검토 맵으로 보여준다. 명시적으로 채택한 범위만 라이브에 반영한다.

정지 이용 자세와 수영2컷 원칙은 유지한다. 앉고 일어나는 중간/호흡 모션, 숨은 실내 인물, 시설 미정 상태의 장발·치마·체형 확장은 자동 재개하지 않는다.

## 그대로 남는 진단

V6/V7의 눕기/앞 평상 머리 비례 진단은 과거 기록으로 보존한다. V8의 눕기·양반다리·뒤 슬라이드 독립 표시 보완을 시설의 받침/착석 인증이나 전체 인물 승인으로 확대하지 않는다. 족욕 발 약3–5논리px(기존 허용2px), 안마 뒤 머리/등받이, 슬라이드 출구[0,0]/그림[2,0] 및 회전별 경로는 기존 테스트 시설의 보류 기록이다. 시설 확정 이후 새 치수/원본에 맞춰 다시 판단한다. 걷기·뒤 방향·외형 호환의 독립 과제는 최신 V8 `walk-integrated/` 후보에서 검증 완료했으며, 이는 시설 보류를 해제하지 않는다.

# 통합 에셋 스킬 독립 시험 계획

평가자는 이전 대화와 기대 답안을 받지 않는다. 통합 스킬, 필요한 원시 파일, 자연어 작업 요청만 전달한다. 임시 디렉토리에 출력하고 실게임 에셋·저장소는 수정하지 않는다.

- 시설: 승인 드라이룸 재생성의 decoded RGBA 4방향 일치; 동일 구조/등록을 유지한 명암 후보 실제 생성; 원본/후보 이미지 검토. 재생성과 신규 자산 제작 능력을 구분한다.
- 기구/NPC: 단일 바나나 후보, 원시 manifest/이미지/depth와 현재 게임 코드. 시험자가 h07 이미지를 제거해 둔다(평가자에게 알리지 않음). 누락을 탐지하고 4방향 NPC와16방향 기구를 혼동하지 않는지, 접점 검수의 한계를 과장하지 않는지 본다.
- 바닥: 현재 구현과 시험용 출력 폴더. 타일/데크 편집·재료 경계·물 효과·정지 및 정리 생명주기를 실행 검사하고 모의/실게임 검증을 구분하는지 본다.
- 렌더러 음성대조: 비평면 사각형과 SHA 불일치 텍스처를 각각 투입해 오류 종료와 PNG 미생성을 확인한다.

문법검사와 링크검사는 패키징 확인이다. 독립 작업 결과나 미술 품질 통과와 같지 않다. 새 형상 전체 제작, 모든100종 재생성, 모든 기구×외형 접점 및 사용자 미술 승인은 이번 검사만으로 주장하지 않는다.

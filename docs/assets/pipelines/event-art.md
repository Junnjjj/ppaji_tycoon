# 사건 배경 삽화 작업 지시서 (P1.5-B ②)

**지금 상태: 계약 9종 · 반입 0장.**
사건 상자(`.kevent-stage`)는 지금 `placeholder` 상태다 — `--sk-*` 토큰만으로 하늘 띠 ·
지면 띠 · 소품 실루엣 · 비네트를 겹쳐 **무대처럼** 보이게 해 뒀다. 그 자리에 진짜 그림을
깐다. 레이아웃·문구·터치 계약은 **안 바뀐다** — `data-stage-state` 가 `art` 로 바뀔 뿐이다.

⚠ 대상·크기·프롬프트의 정본은 **`src/assets/ui-icons.json`** 의 `art` 배열이다.

---

## 1. 무엇을 뽑나 — 9장

`CardTheme` 8종과 **1:1**이다. **새 테마를 만들지 않는다** — 테마가 늘면 sim 데이터가 같이
늘어야 하고, 그건 그림 작업이 아니다.

| id | 배경 |
|---|---|
| `crowd` | 붐비는 플로팅덱 · 난간에 줄 선 손님 |
| `weather` | 비 오는 넓은 강 · 먼 산에 낀 물안개 |
| `safety` | 물가의 안전요원 망대 · 난간에 걸린 구명환 |
| `publicity` | 기둥 사이 강변 현수막 · 뒤 도로로 들어오는 버스 |
| `staff` | 매점 뒤편 · 걸이에 걸린 유니폼 |
| `market` | 창고 옆에 선 작은 배달 트럭 |
| `facility` | 짓는 중인 나무 데크 · 쌓인 널판과 목재 |
| `environment` | 새벽 강 · 뒤 산 능선 · 물 위 물안개 |
| `celebrate` | 노을 진 빠지 전경 · 불 켜진 플로팅덱 (축하 모달 기본) |

**규격**: 480×160px (무대 240×80텍셀 × 2) · PNG · **불투명해도 된다**.
파일명은 계약 id 에서 `event/` 를 뗀 것 — `event/crowd` → `crowd.png`.
넣는 곳은 **`public/assets/event-art/`**.

## 2. 어떻게

### ⚠ 배경만 그린다 — 전경은 게임이 얹는다

이게 이 지시서에서 **가장 중요한 규칙**이다. `composeEventScene` 이 그 위에 게임의
**실제 손님·시설 스프라이트**를 올린다. 그래야 "이 사건이 **내 빠지**에서 일어났다"가 된다.

배경까지 전경을 그리면 **화면의 물체와 삽화의 물체가 따로 논다** — 삽화 속 손님과 그 위에
선 진짜 손님이 다른 그림이 되어 즉시 「무대 뒤에 세운 벽」으로 읽힌다.

→ **앞쪽 1/3 에는 사람도 물체도 두지 말 것.** 거기가 전경이 앉을 자리다.

### 스타일의 정본은 첨부 이미지

**반드시 첨부**: `art-reference/ui-concept/concept-30-ppaji-target.png`.
평균 채도 **0.54** — 우리 크림 팔레트(0.55)와 거의 같다. 그래서 배경을 깔아도 팔레트
계약이 안 깨진다. 바꿔야 하는 것은 채도가 아니라 **색상 분포**다 (우리는 주황에 몰려 있고
하늘·청록이 얇다 — 배경이 그 얇은 쪽을 채운다).

### 3:1 가로 띠라는 것을 잊지 말 것

480×160 은 **아주 납작하다.** 세로로 쌓는 구도(하늘 위 / 산 가운데 / 물 아래)를 그대로 쓰면
각 띠가 50px 밖에 안 된다. **가로로 흐르는 구도**로 잡을 것 — 강이 화면을 가로지르고,
산 능선이 위쪽 1/3 에 낮게 눕는 식이다.

## 3. 판정

```bash
npx tsx tools/check-ui-icons.ts            # 아이콘과 같은 게이트가 배경도 잰다
```

| # | 무엇 | 떨어지는 조건 |
|---|---|---|
| ③ | 크기 | 480×160 이 아니다 |
| ⑤ | 팔레트 | 팔레트 밖 화소가 2% 초과 |
| ⑦ | 계약 밖 | 계약에 없는 파일이 디렉터리에 있다 |

⚠ 배경은 **투명 배경·대비 검사를 안 받는다** (아이콘과 다른 점). 무대를 다 덮는 것이
정상이고, 그 위 글씨는 상자의 카피 영역에 있지 그림 위에 있지 않다.

⚠ **떨어진 장은 버린다** — 그 테마만 `placeholder` 무대로 떨어지고 화면은 안 깨진다.
**9장을 다 요구하지 않는다.**

---

## 4. 하면 안 되는 것

- ⚠ **앞쪽 1/3 에 물체를 두지 말 것** (§2) — 전경이 앉을 자리다
- ⚠ **글자를 넣지 말 것** — 한국어 계약 밖의 텍스트가 화면에 뜬다
- ⚠ **원경 배경을 "무대 뒤에 세운 벽"처럼 그리지 말 것.** 이 저장소는 그 실패를 **두 번**
  했다 (`art-reference/competitor/README.md`). 사건 상자는 지도가 아니라 **장면**이라
  이 규칙이 덜 빡빡하지만, 지평선을 한가운데 그어 놓으면 같은 인상이 난다
- ⚠ **새 테마를 만들지 말 것** — `CardTheme` 8 + 축하 1 이 전부다

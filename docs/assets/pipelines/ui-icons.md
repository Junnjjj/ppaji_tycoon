# UI 아이콘 작업 지시서 (P1.5-B ①)

**지금 상태: 계약 57종 중 AI 대상 44종 · 반입 0장.**
화면의 표식은 **전부 이모지 글리프**다 (`src/ui/icons.ts`). 기기·OS 마다 다른 그림이 나오고,
게임 아트와 재질이 안 맞고, 크기·정렬이 흔들린다 — 그걸 픽셀아트로 갈아 끼우는 일이다.

읽는 순서가 곧 하는 순서다 — §1 무엇을 → §2 어떻게 → §3 판정 → §4 하면 안 되는 것.

⚠ **이 문서는 목록을 손으로 적지 않는다.** 대상·크기·프롬프트의 정본은
**`src/assets/ui-icons.json`** 이고, `prompt` 필드가 곧 장당 지시서다
(`manifest.json` 의 `source: 'ai'` 규약과 같다). 목록이 필요하면 거기서 읽을 것.

## 2. 어떻게

### 스타일의 정본은 **텍스트가 아니라 첨부 이미지**다

**반드시 첨부**: `art-reference/ui-concept/concept-30-ppaji-target.png`
(784×1426 · 강변 펜션 · 플로팅덱 · 바나나보트 · 산. 색상환 하늘 35% · 주황 27% · 청록 18% ·
평균 채도 0.54).

프롬프트로 스타일을 **다시 기술하지 말 것.** 이 저장소가 확립한 원칙이고
(`ppaji-pixel-asset` 스킬), 글로 적은 스타일은 매번 다른 그림을 낸다.

### 색은 팔레트 안에서

허용 색 = **`art-reference/palette-proposed-39.json` 39색 + HUD 크림 토큰**
(`src/ui/style.css` 의 `:root`). 게이트가 **가장 가까운 팔레트 색과의 거리 24** 로 잰다 —
정확 일치는 아니지만 형광색·회색조는 바로 걸린다.

### 한 시트에 많이 넣지 말 것

⚠ **4-up 이면 해상도가 1/4 로 떨어져 색이 샌다** (K53 실측 — 차양 빨강이 주황으로 샜다).
한 번에 **한 장**, 물체마다 로지컬 폭의 6배 이상으로 뽑고 48×48 로 줄인다.

## 3. 판정 — 우리 게이트가 한다

```bash
npx tsx tools/check-ui-icons.ts            # 반입 현황 + 반입분 판정
npx tsx tools/check-ui-icons.ts --selftest # 자가 실제로 재는지 (6/6 잡힘)
```

| # | 무엇 | 떨어지는 조건 |
|---|---|---|
| ③ | 크기 | 48×48 이 아니다 |
| ④ | 투명 배경 | 네 모서리 중 하나라도 불투명 · 화면의 92% 초과를 덮는다 |
| ⑤ | 팔레트 | 팔레트 밖 화소가 2% 초과 |
| ⑥ | 대비 | 가장 어두운 잉크가 크림(`#f0d5a4`) 위에서 **3:1 미만** |
| ⑦ | 계약 밖 | 계약에 없는 파일이 디렉터리에 있다 |

⚠ **떨어진 장은 버린다. 그 id 만 글리프로 떨어지고 화면은 안 깨진다**
(Phase G `HybridProvider` 와 같은 규칙). **100% 를 요구하지 않는다** — 통과분만 반입한다.

⚠ **⑥ 이 가장 잘 걸린다.** 크림 팔레트 위에 크림색 아이콘을 그리면 사람 눈에도 안 보인다.
잉크는 따뜻한 진갈색(`#4a2f14` 언저리) 쪽으로 잡을 것.

## 4. 하면 안 되는 것

- ⚠ **글자를 넣지 말 것.** 아이콘 안의 텍스트는 어느 크기에서도 안 읽히고, 한국어 계약도 못 지킨다
- ⚠ **바닥 그림자를 넣지 말 것.** 아이콘은 UI 위에 뜨는 표식이지 지면에 선 물체가 아니다
  (시설 스프라이트의 접지 규칙과 **반대**다 — 여기서 그림자는 크림 위 물때가 된다)
- ⚠ **배경을 채우지 말 것.** 흰 사각형이 크림 패널 위에 앉으면 게이트 ④ 가 잡는다
- ⚠ **13종 절차 대상을 뽑지 말 것** (§1) — 계약에 없는 파일은 게이트 ⑦ 이 잡는다
- ⚠ **한 장을 두 번 뽑지 말 것.** 두 번째가 첫 번째를 망가뜨릴 수 있다 (A군 선례)

## 5. 반입 뒤에 우리가 할 일 (받는 쪽 몫 아님)

- `setIconArt()` 에 통과분을 건다 — id 마다 독립이라 부분 반입이 정상이다
- ⚠ **AI 대상 아이콘의 호출부가 지금 문자열이다** (`icon('course')` → `string`).
  문자열은 그림이 될 수 없으므로 그 자리들을 `iconEl()` 로 옮겨야 한다 (계획 §8-17).
  이 일은 그림이 오기 전에도 할 수 있지만, 옮겨 놔도 그림이 없으면 화면이 그대로라
  **반입과 같이 하는 편이 검증이 쉽다**

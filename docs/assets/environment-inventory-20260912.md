# 맵·벽·주변 환경 에셋 정리

2026-09-12 사용자: 나머지 시설 20종은 유지. 다음 관심은 맵, 벽, 주변 건물.
이번 단계는 현황·제작 후보 정리이며 새 이미지 생성/게임 교체는 하지 않음.

| 영역 | 확인된 현황 | 후속 후보 |
|---|---|---|
| 지형 | 잔디·모래·돌길·데크·물·해안·절벽 source-v1 기본 채택. 도로·실내바닥·다리 기존 atlas 존재 | 유지 후 전체 맵에서 연결 품질 확인 |
| 해안 | 곡선 후보는 채택 미완료, 기존 8종 오버레이는 사용자 거절 | 별도 후속. 완성으로 표시하지 않음 |
| 벽·문 | 유리 계열 벽 4방향 + 문 4방향, 타일 경계 배치/통행 구현 | 연결 이음새 검증, 목재 울타리·돌담·수변 난간·출입 게이트 후보 |
| 먼 배경 | 산·능선·맞은편 강변 3레이어 | 현행 유지하며 가까운 환경과 색 비교 |
| 주변 장식 | 7역할, 12개 배치 계획. 집=방갈로, 상점=매점, 차량=주차장 스프라이트 재사용 | 전용 주변 건물/차량 아트 필요 여부 검토 |
| 조경·소품 | 화단·화분·가로등·안전표지 등 기존 존재 | 큰 나무·관목 군집·정류장 등 선택 제작 |

첫 컨셉 후보 6종(제안, 제작 승인 아님): 작은 단독주택, 2층 동네 상가, 펜션, 소형 호텔, 편의점, 관리창고.
기존 시설·NPC와 같은 지면 스케일 및 재질. 주변 건물은 층수로 높이 차이를 낸다. 낮은 건물은 가까이, 높은 건물은 바깥 뒤쪽으로 배치하여 플레이 영역을 가리지 않는다.
벽 세트는 직선 양축·코너·끝단·문 연결을 한 세트로 검토한다.

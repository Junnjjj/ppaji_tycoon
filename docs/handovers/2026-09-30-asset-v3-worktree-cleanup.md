원본9.33GB를 중복 제거 후 **6.64GB /18개 tar.zst**로 압축했다. 모든 일반 파일은 압축 해제 스트림의 SHA-256까지 원본과 대조했다.

원본 워크트리 삭제에 의존하지 않으며, 대용량 압축본은 GitHub가 아닌 이 디스크에 보관한다.

보관 폴더에서 `python3 restore.py --find 검색어`로 찾는다.
전체 복원은 `python3 restore.py --destination /Volumes/외장디스크/복원폴더`로 실행한다.
압축 파일 해시를 먼저 확인하며, 비어 있는 복원 폴더와 추가 공간이 필요하다. 원래 소스/생성 원본/검수/백업 폴더 구조를 복원한다.
부분 묶음만 풀면 다른 묶음을 참조하는 심볼릭 링크는 미완성일 수 있다.

`.git`, 의존성 설치 폴더, 재생성 가능한 빌드/캐시는 제외했다. 과거 이미지가 참조하던 dist 파일6개는 보존했다.
복원된 runtime/public 링크3개는 메인 에셋을 사용하며 Python 링크3개는 시스템 설치에 의존한다.
의존성 설치용 node_modules 링크1개는 재설치가 필요하다. 자세한 내용은 `symlink-audit-final.json`.

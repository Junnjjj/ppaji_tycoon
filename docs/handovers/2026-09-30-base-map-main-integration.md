# 기본맵 에디터 메인 통합 — 2026-09-30

## 변경

메인의 기존 ImageGen/준비실/진입로 변경 위에 검수된 기본맵 에디터를 통합했다.
일반 URL은 게임, `?editor=1`은 편집기이며 `이 맵으로 플레이`는 별도 테스트 탭을 연다.
새 게임에 넓은 S자 강, 변화를 준 모래사장, 외곽 인도·마을·차량, 간격을 둔 나무와 연속 유리벽 화단을 적용한다.
물 가림과 차량 아트 재생성 문제를 수정하고 유리벽 화단과 겹치는 별도 화분/화단을 제거했다.

일반 저장 키 `pj.save`/`pj.profile`을 유지하고 에디터 저장을 분리한다.
저장 버전6은 기존96×72 지형/높이/자연바닥과 시설/돈/진행을 보존하며96×120으로 확장한다.
기존 저장의 배치를 새 기본맵으로 덮어쓰지 않는다.
미추적이던 ImageGen/compact-boundary/준비시설 런타임 에셋도 코드와 함께 포함한다.

## 검증

- 메인 경로에서 TypeScript 검사와 프로덕션 빌드 통과.
- 관련 Vitest16파일92테스트 통과.
- `npm run test:editor`:13개 통과. 메인에 테스트 실행 명령을 추가했다.
- ESLint 및 UI 정적 검사/음성 대조군 통과.
- ego-browser에서 일반 게임, 에디터, 플레이 팝업, 강/화단/마을 화면 확인.
- 일반 저장을 버튼으로 저장하고 새로고침 후 돈12000/시설38/높이120/버전6 유지 확인.
- 에디터 진입 후 일반 저장 유지. 마을 화면 에셋 HTTP 실패0.

전체 회귀 성공을 의미하지 않는다. 앞선 전체 실행에서 기존 메인에도 있는
`p49a1.test.ts` 기구 수 기대35/실제39 실패와 장시간 course 봇 테스트 시간 초과가 확인되어 중단했다.
나무 개별 삭제 UI/저장은 아직 미구현이다.

# 빠지 스토리 — 「그림 우선」 조합·구매 UI 계획 (v1, 2026-09-11)

> 정본. 원작(워터파크 스토리)의 **「모든 정의에 그림이 있고, 창은 그 그림을 격자로 깐다」** 문법을 우리 조합·구매·선택 화면 전부에 옮긴다.
> 실측 근거: `art-reference/competitor/pss-ui-*.png` 8장(플레이 영상 2편에서 2026-09-11 추출, README 표) · `docs/research/pss-image-ui-direction-2026-09-11.md` §2~§5 · Stitch 목업 `ppaji/docs/shots/stitch-*.png`.
> 그림은 이 세션이 만들지 않는다 — **주문서 `docs/assets/pipelines/ppaji-picture-sheet.md`** 를 ChatGPT(이미지 생성)에게 넘긴다. 코드는 그림 없이도 폴백으로 돈다(P56-a).

## 1. 원작 문법 — 실측 8장에서 뽑은 규칙 (이것이 「워터파크 스토리만큼」의 기준)

| # | 규칙 | 근거 |
|---|---|---|
| G1 | **정의마다 그림 하나.** 시설·타일·아이템·재료·요리·선물 전부. 글자는 이름·숫자뿐 | build/shop/tiles 격자 |
| G2 | **격자는 3열, 카드 한 장 = 큰 그림 + 좌하 `×N`(보유) + 우하 가격 + 우상 배지(선물/NEW/Indoor).** 선택 카드는 노란 채움, 격자 오른쪽에 세로 스크롤바 | `pss-ui-build-grid` |
| G3 | **창 아래 두 줄이 고정**: 「이름 · (분류 칩) · No./Owned N」 한 줄 + 설명 한 줄. 카드를 탭하면 이 두 줄만 바뀐다 | build·shop |
| G4 | **분류 탭은 픽셀 아이콘 6개**, 새 항목이 생기면 탭 위에 NEW 배지 | build·tiles |
| G5 | **살 수 없는 것도 자리에 있다** — `SOLD OUT` 띠, 잠금은 회색. 빈 상태 화면이 없다 | shop |
| G6 | **배치·구매는 지도 위 팝**으로 값을 말한다: 「800G ×1」 + Rotate/OK | `pss-ui-place-pop` |
| G7 | **조합 결과는 「장면 카드」**: 위에 일러스트(대상 + 손님 둘) + 총점(인기 24), 아래 축 카드 셋(색상환·향 칩·온도), 각 카드에 강도 5칸 게이지 + 돋보기 | `pss-ui-item-effect` |
| G8 | 정보 창도 같은 세 카드 + 「+ 아이템 추가」 큰 버튼 한 줄 | `pss-ui-pool-info` |
| G9 | 보상·편지는 **장면 일러스트** 위에 물건 그림이 앉는다(「받아주세요!」) | `pss-ui-gift-letter` |
| G10 | 획득은 「You got the Lemon!」 한 줄 + 손님 머리 위 게이지 — 모달이 아니다 | `pss-ui-item-pickup` |

우리 색 토큰(크림 `#fbe7c3` · 바 `#f8d9a2` · 윤곽 `#8c5e2b` · 머리 `#3b4a9e` · 노란 선택 `--select-fill`)은 그대로다. 옮기는 것은 **문법**이지 색이 아니다.

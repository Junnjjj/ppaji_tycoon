## 3. 왜 「원작보다 덜 전문적」으로 보이는가 — 원인 셋

1. **규격이 아니라 값의 누적.** 6·7·5 라는 숫자(글자·반경·톤)는 디자인이 아니라 P12~P57 동안 창을 하나씩 만들며 붙은 값이다. `check-ui-surface.mjs` 가 색만 지키고 **크기·반경·톤은 안 지킨다.**
2. **행이 설명을 한다.** 원작은 값은 위(숫자·게이지), 설명은 아래 두 줄 띠에 둔다. 우리는 `.krow` 하나에 라벨·값·설명을 다 넣어 행마다 길이가 다르고 캡슐이 늘어난다. 「desc 에 효과를 다시 적지 않는다」(K50-②)의 화면 버전이다.
3. **빈 상태·잠금이 첫 화면.** 장날 21장 잠김, 공방 잠긴 부품 12장, 건설 잠긴 카드, 빈 결과 박스 5곳. 원작은 **없는 것을 안 보여 준다**(K40 규칙이 건설 창에만 적용되어 있다).

그리고 원인이 아닌 것: **픽셀 밀도·배율·그림**은 원작과 같다(P53 §1 · P56-b). 프레임 그림을 산다고 1~3 이 고쳐지지 않는다 — 다만 「창이 지도와 분리되어 보이는 것」(테두리·머리 무늬)은 그림이 답이다.

## 4. 원작 UI 문법 요약 (프레임 8장에서, 규격표의 바탕)

- **창**: 전폭, 파란 두꺼운 테두리(안쪽 흰 선), 머리는 타일 무늬 띠 + 제목 가운데, 본문 흰 바탕, **아래 두 줄 띠**(이름 · No. N / 설명 한 줄). 크기는 내용과 무관하게 같다.
- **격자**: 3열 그림 카드, 카드 = 큰 스프라이트 · 좌하 `×N` · 우하 가격 · 우상 배지. 선택 = 노란 채움. 세로 스크롤바가 오른쪽에 보인다.
- **숫자**: 노란(값)·파란(돈) 픽셀 숫자, 단위는 작은 글자. 게이지는 5칸.
- **홈**: 상단 2줄(연도·계절·날씨 / 요일·시각 크게), 우측 아이콘 5(잠긴 칸 `?`), 하단 핑크 배너 1줄 + 바(SAVE · 초상+이름+Lv · MENU).
- **지도 위**: 가격 팝(「800G ×1」) + Rotate/OK, 구매 팝(아이콘 ×N), HP 배터리, ★ 게이지.
- **결과 카드**: 일러스트 장면(풀 + 손님) 위, 카드 3(색·향·온도) 아래, 확인 1.

## 5. 우리에게 이미 있는 것 (다시 만들지 말 것)

토큰 계약(`style.css` :root, 색 0 하드코딩) · 패널 표면 셋(시트·전면·떠 있는 것) · `PictureGrid` 3열 카드 · `kwin` 머리/본문/발 구조 · 그림 396장 + 장면 4 · 초상 10 · Galmuri11 픽셀 폰트 · 태블릿 UI 배율. **스킨은 이 위에 `border-image` 로 얹을 수 있다** — 코드가 아니라 `style.css` 의 일이다.

### 6.3 코드를 안 갈아엎고 DOM HUD 를 스킨하는 방법

- **CSS `border-image`** 네 줄(`-source/-slice/-width/-repeat`)이면 `.kwin`·`.ksheet`·`.kbtn` 에 PNG 프레임이 붙는다. ⚠ `image-rendering: pixelated`(Chrome/Safari) + `crisp-edges`(Firefox) 둘 다. ⚠ border-image 에 image-rendering 이 먹는지 **Safari 15 실기기**로 잰다 — 못 믿으면 Northforge 처럼 **2x 로 미리 굽고** slice 도 2배(우리 S=2 정책과 같다). ⚠ 늘어나는 변·중앙 띠는 단색이거나 축 방향 균일이어야 한다. 생성기: https://leanrada.com/wares/9-slicer/ · https://alanrobinsondev.itch.io/9slice-pixel-art-4css
- **Aseprite**: AseSlicesTool · Export Slices 스크립트 · PixMold UI Crafter(9-slice·베벨 템플릿). CSS 직행 출력은 없다 — 인셋 JSON 을 `style.css` 변수로.
- **한글 픽셀 폰트**: Galmuri 7/9/11/14(OFL, 한글 4,358자 — 완성형 전부가 아니다) · **Neo둥근모 Pro**(OFL, 가변폭·합자) · 둥근모꼴+Fixedsys(PD) · **Mulmaru**(OFL, 12px, **한글 11,172자 전부**) · Pretendard(본문). 픽셀 폰트는 **네이티브 px 의 정수배**(Galmuri11 → 24px)로. 손님 이름·메뉴명처럼 자유 문자열 자리는 Mulmaru/Pretendard 폴백을 뒤에.
- **Stitch/Figma**: 레이아웃 순서 참고까지(9-11 실측). 픽셀 스킨은 못 낸다. 2026-03 부터 Stitch → Figma 붙여넣기(Auto Layout 보존)가 되므로 토큰을 Figma 스타일로 굳히는 용도.

### 6.4 카이로소프트는 무엇을 하나 · 비슷한 폴리시의 인디

## 7. 제안 — 순서

「사야 하나」에 대한 답: **프레임 그림은 사고($10), 규격은 우리가 정하고, 마감 한 번은 사람에게($300~800).** 에셋 팩 하나로 전문적이 되지 않는다 — §3 의 원인 1~3 은 규격표와 화면 정리로만 닫힌다.

|---|---|---|---|
| **P59-a 규격표** | `style.css` 토큰을 **글자 3단(`--fs-title/body/cap`) · 반경 2(창 10 · 안 6) · 버튼 높이 1(`--tap`) · 창 톤 2(일반·축하)** 로 줄이고, `check-ui-surface.mjs` 가 **크기·반경·톤 값의 수**를 지킨다(색 0 하드코딩과 같은 방식). 창은 **늘 `top 64 · 전폭`**(`kfit` 는 높이만 줄이고 자리는 위에 붙인다). `.krow` 값에 **문장 금지** — 설명은 창 아래 「두 줄 띠」(`.kwin-foot` 재사용) | 중 (CSS + 검사) | §3-1 · §3-2 · 창 자리 |

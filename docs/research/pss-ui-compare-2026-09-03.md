# 워터파크 클론 vs 원작 — 실제 화면 비교 (2026-09-03)

> 방법: ego-browser 로 배포본(`http://100.114.231.15:5179/`)을 393×852 로 열어 9화면을 찍고, 유튜브 플레이 영상 2편
> (초반 iOS 「no commentary part 1」 · 엔딩 「All Complete」 13년차)에서 프레임 7장을 뽑아 나란히 봤다.
> 위키가 말해 주지 않던 **화면 문법**이 여럿 나왔다. 아래는 원작에 있고 우리에게 없는 것부터.

## B. 우리 화면에서 보인 문제 (스스로 찍어 본 것)
- **B1** 건설 창: 카드 3장뿐(편의 탭 화장실·샤워·음수대). 원작은 탭당 6~10장이 스크롤로 보인다 — 시작 해금이 적다.
- **B2** 풀 편집 독이 화면 **하단 45%** 를 먹는다(파기/메우기/아이템/실내 5탭 + 타일 칩 + 버튼 2줄). 원작은 지도 위 얇은 독 + 아이템은 별창.
- **B3** SNS 첫 화면 「아직 글이 없다」 빈 상태. 원작은 첫날부터 NEW 배지가 붙는다(개장 글).
- **B4** 심사 창의 카드 2장이 세로로 길어 한 화면에 1.5장. 원작은 계열 하나 = 창 하나.
- **B5** 상점 첫 화면 「진열이 비었다 — 17시」. 원작은 첫날 17시 전에도 물건이 보인다(잠금 표시).
- **B6** 데스크톱(1904px)에서 열면 토지가 모래 바다의 섬처럼 보인다 — 폰 전용이라 무해하지만 데스크톱 공유 링크에서 인상이 나쁘다. FPS 32(ego-browser).

## C. 우선순위 제안
1. **U1 아이템 재고** — 시스템 차이 중 가장 큰 것. 상점에서 사서 재고로 쌓고 투입 때 소비(가격 0). 소원·인증 보상도 「재료 ×3」이 자연스러워진다.
2. **U2 + U3** — 심사 창(심사위원 대사·참가상·합격 상품)과 풀 정보 창(세 카드·강도 게이지·이름 바꾸기). 이미 데이터가 다 있어 표현만 바꾸면 된다.
3. **U10/U11/U12** — 시작 자금 4,400G · 유지비를 원작 눈금으로, 첫 화면에 포장 바닥·유리 펜스·도로. 밴드 재측정 필요.
4. **U6** — 손님 만족 Lv 을 티커 뉴스 + 하단 바 Lv 배지로 노출(티켓 곡선은 이미 G30).
5. **U4** — 일별 방문 그래프는 시즌 카드에 넣거나(결정 유지) 일일 카드를 「그래프 한 장」으로만 켜기.
6. B1~B5 UI 다듬기.

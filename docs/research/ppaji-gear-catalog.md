# 빠지 수상 기구 카탈로그 — 실지 조사 (2026-09-07)

조사 대상: 한국 강변 수상레저 「빠지」(가평·청평·춘천·홍천·설악면 일대 북한강/홍천강).
방법: ego-browser 로 네이버·구글 검색 + **업체 공식 사이트 12곳** + 후기 블로그 + 법령·소비자원 자료.
원자료 URL 은 §5.

⚠ **이 문서는 조사 기록이다.** 게임 데이터를 바꾸는 결정은 `docs/plan-ppaji-story.md` 가 정본이고,
여기 §4 의 제안은 후보일 뿐이다.

4. **플라이피쉬** (10/12) — 스릴 최상위, 그래서 **1회 제한**을 거는 곳이 있다
5. **팡팡 / 와일드팡팡** (9/12)
6. **밴드웨건** (8/12) — 앞 3명 앉고 뒤 3명 서서 탄다
7. **마블 계열** (자이언트마블·빅마블·4인마블, 8/12)
8. **워터슬라이드** (대형, 8/12) — 기구가 아니라 뭍/바지선 시설인데 이용권에 늘 끼워 판다
9. **와플 / 와풀 (도넛)** (7/12)
10. **핵사곤 / 헥사** (6/12)

### 「생각보다 많았던 것」

기구가 33종이 아니라 **31종의 견인 기구가 업체마다 다른 이름으로 갈라져** 사실상 60개 넘는
간판이 돌아다닌다. 같은 원판(6인 도넛형 튜브)이 어디선 **와플**, 어디선 **와풀**, 어디선
**도넛**, 어디선 **로투스**다. 반대로 **「단군」·「닌자」·「난리보트」·「개구리」·「호떡」·
「G-RAL(지라알)」·「팽이」처럼 제조사 이름이 아니라 그 빠지가 붙인 별명**이 그대로
간판이 된 것이 많다 — 이건 우리 게임의 「공방에서 개조해 이름이 바뀐다」와 정확히 같은
문화다. 그리고 예상 밖으로 **기구 종수 자체가 마케팅의 1순위 문구**였다(「17종 최다」·
「15종」·「12종」·「8종」이 업체 첫 화면 카피다). 마지막으로, **한 시설이 견인·동력·플로팅·
숙박·바베큐·풀파티까지 한 덩어리로 파는 것**이 표준이라 「기구 카탈로그」와 「패키지 구성」이
분리되지 않는다 — 빠지의 상품 단위는 기구가 아니라 **하루**다.

### (c) 우리에 있는데 실지엔 드문 것

| 우리 기구 | 실지 | 제안 |
|---|---|---|
| **하이드로포일** (taste 10) | 국내 빠지에서 **한 곳도 못 찾았다**. 웨이크 계열 최상급 개인 종목 | 최종 해금 자리는 **잠수 제트보트**가 더 맞다 — 하이드로포일은 강습 트리 끝으로 옮기거나 이름을 바꾼다 |
| **에어체어** (air chair) | 마찬가지로 없음 | 위와 같음 |
| **마린제트** | **제트스키와 같은 것**이다(별칭) | 중복 — 하나로 합치고 자리를 UFO/마블에 준다 |
| **워터롤러** | 견인 기구가 아니라 **에어바운스 아쿠아파크 모듈** | `class: 'rig'` 로 옮기는 것이 맞다(D77 이 이미 그 방향) |
| **플라잉카펫 · 좌우그네** | 대응 간판을 못 찾았다 | 실지 이름이 없으니 **개조판 이름**으로 내리고 원판 자리를 실지 기구에 |

| **벌집튜브 vs 육각튜브** | **같은 기구의 두 별칭** | 하나를 다른 기구(UFO 등)로 교체 |
| **블롭점프가 견인 기구** | 실지는 **고정 플로팅 시설**이고 둘이 있어야 성립 | `class: 'rig'` + `team: 2` 로 옮긴다 — §14.4 초안 5번과 이미 일치 |

### 한 줄 결론

**견인 축의 종수(30)는 실지(31)와 이미 같다.** 부족한 것은 종수가 아니라 **(1) 정원 폭**
(실지는 2인~12인인데 우리는 3~6에 몰려 있다), **(2) 스릴 0 의 관광 상품**(보팅 투어),
**(3) 「몇 종 몇 회」 이용권 구조**, **(4) 자가 추진(paddle) 상태**다. §14.4 의 기구 22 초안은
플로팅 쪽을 잘 덮고 있고, 여기 조사가 더한 것은 **UFO·마블 3단·바이퍼·잠수 제트보트·
장애물 코스·보팅 투어** 여섯이다.

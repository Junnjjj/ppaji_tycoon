v2 (헤르메스 리서치 + 사용자 방향 반영): ① 우리에게 이미 있는 축(시설 개선 5단계·
소원·의뢰·숨은 콤보)을 **최대 재사용** — 새 시스템 최소화 ("너무 복잡한 건 지양") ②
도파민 연출은 필수이되 **팝업 과다 금지 가드레일**과 한 몸으로 ③ 목표 3슬롯(A 1~2분 /
B 5~10분 / C 진행률 가시) 규칙을 설계 기준으로 채택

원천: 사용자 7시간 플레이 관찰 2건 + 위키 수집 2건
(`pss-facilities-systems.md` · `pss-menu-requests.md`, 2026-08-20).
목적: "후반에 할 게 없다"(CLAUDE.md 다음 할 일 3)와 "공간을 채울 뿐 고민이 없다"
(사용자 지적)를 PSS 가 실제로 푼 방법으로 고친다. **구현 전 사용자 검토용.**

## 진단 — 중독 엔진 셋, 우리 갭 셋

| PSS 엔진 | 작동 원리 (수집 실측) | 우리 상태 |
|---|---|---|
| ① 회피 퍼즐 | 상성 ⊚/◯/**△(−50%)**. ◯이 다수라 "나쁜 조합을 피하는" 제약 만족 문제 | 콤보 73종 **전부 가점** — 다 켜면 이기는 최대화 문제. 감점 축이 0 |
| ② 그릇 속 그릇 | 판매 시설마다 메뉴 5슬롯 + 4카테고리. 아이템 3속성이 **서로 다른 자원**(체류·현금·평판)에 꽂힘. 레시피 ~139종 발견 | 시설 = `fee` 숫자 하나. 내부 구성 축이 통째로 없음 |
| ③ 돈 다음 화폐 | 후반 잉여 현금의 출구(재료 상점·손님 선물) + 사이드 심사 19개(보상=콘텐츠) + 무지개 풀(관리 해방 목표) | 잉여 현금 출구 0. 심사는 단일 사다리 5단. 완성형 콘텐츠 0 |

핵심 통찰 (사용자): **돈이 남아도는 건 PSS 도 같다.** 차이는 돈이 의미를 잃는 시점에
다른 희소 자원(자리·지식·구성)으로 갈아타게 해 주는 다리의 유무다.

숫자 하나가 이를 요약한다: PSS 는 `Cost/Popularity ≈ 90` 이 전 구간 일정 —
상위 시설은 "효율이 좋은 것"이 아니라 **같은 자리에 더 많이 넣는 것**이고,
병목은 언제나 돈이 아니라 **자리**다.

## 채택안 — 비용 순

### P1 (싸다 · 기존 시스템 확장)

- **A. zone 콤보 면적 비례** — PSS 의 SE/Area Boost 는 풀 크기에 곱해진다.
  우리 zone 콤보 3종은 상수 → 구역 면적 비례로. permitArea(40→500)와 곱하면
  "허가를 어디에 쓸 것인가"가 곧 결정이 된다. (기존 파일 3곳, 밸런싱 1회)
- **B. 상성 감점(△) 도입** — `need` 9종이 이미 9×9 매트릭스 재료다. JSON 에
  "이 수요끼리 인접하면 −" 를 넣고 (예: 위생 옆 먹거리 −, 스릴 옆 휴식 −)
  콤보 평가기에 감점 축을 더한다. 불변식 3(데이터가 정의) 그대로.
  ⚠ PSS 처럼 **무효(◯)가 다수**여야 한다 — 감점 도배면 스트레스 게임이 된다.

### P2 (중간 · 새 콘텐츠 축, 새 시스템은 아님)

- **C. 사이드 심사** — 등급 사다리는 그대로 두고 옆에 병렬 심사 N종
  (예: 위생王·스릴王·경관王·빠지 오리지널 인증). 조건은 `evaluateCondition`
  재사용, **보상은 현금이 아니라 콘텐츠**(전용 시설·바닥 종류·손님 유형).
  PSS 24종의 축소판 — 후반 목표 밀도의 최단 경로.
- **D. 손님 선물 = 잉여 현금 출구** — 남는 돈으로 손님 유형에 선물 →
  소원 EXP 가속 (기존 K43 소원 시스템에 꽂힘). 상점 UI 없이 카드/메뉴 한 줄로 가능.

### P3 (크다 · 스펙 필요 — 별도 브레인스토밍)

- **E. 시설 내부 구성 (메뉴 슬롯)** — 판매 시설(자판기·매점·식당·대여소)에
  슬롯 3~5 + 아이템 풀. 아이템 3속성은 반드시 **체류(=이용 수)·현금(=요금)·
  평판(=만족)** 세 자원에 나눠 꽂는다 — 합치면 스탯 하나와 같아져 죽는다.
  ⚠ v4 "재고관리 금지"와 **충돌하지 않음이 수집으로 확인됨**: PSS 재료는 소진
  재고가 아니라 일회성 해금 열쇠, 레시피는 영구 판매. 금지된 건 발주·소모·폐기
  루프다. 이 구분을 채택 시 v4 결정문에 명문화할 것.
- **F. 완성형 콘텐츠** — 무지개 풀의 문법: 조건을 다 갖추면 **계절 관리에서
  해방되는** 시그니처. 우리 대응물 후보: "완전한 빠지"(구역+기구+안전+저녁 전부
  갖춘 강 구역), 시나리오 이월 복리(다음 판에 ×0.3 계승 — 시나리오 6종을 잇는 다리).

### P0 (연출 — 사용자 지정 "필수")

- **G. 도파민 연출 강화** — 이미 있는 뼈대를 살린다: 해금 셀레브레이션(K41)·토스트·
  FX 슬롯 등록부(계약만 있고 **구현 0건** — plan-live-unlock §1). 게이지 90% 도달 예고,
  콤보 발동 순간의 화면 연출, 결산 카운트업, 심사 합격 팡파레.
  ⚠ **가드레일 (헤르메스 §3.3 — PSS 부정 리뷰 1위가 팝업 과다):**
  · 모달은 지금 규칙 유지 (큰 사건만 — 해금·승급·인물·숨은 콤보)
  · 나머지는 전부 비차단 연출 (토스트·FX) + 알림함 적재
  · 강제 중단형은 분당 1회 이하 · 연출 스킵 가능 (`prefers-reduced-motion` 규칙과 동족)
- **H. 목표 3슬롯 감사** — 화면에 항상 A(1~2분)/B(5~10분)/C(진행률) 하나씩 보이는지.
  지금 의뢰 칩 3장이 그 자리인데 **시간축 구분이 없다** — 칩 선정 로직을 "짧은 것
  하나 + 중간 것 하나 + 등급 게이지"로 재배열 (UI 변경 없이 선정 로직만)

### P1.5 (기존 축 재사용 — 새 시스템 없이 깊이)

- **I. 시설 개선의 분기화** — 우리에게 이미 있는 개선 5단계는 "+등급"의 단조 강화다.
  PSS 의 "그릇 속 구성"을 새 메뉴 시스템 없이 얻는 최단 경로: **3단계에서 특화 선택**
  (예: 매점 → 음료 특화(체류+)/간식 특화(현금+)/기념품 특화(평판+)). 아이템 도감 없이
  분기 하나로 "이 매점을 뭘로 키울까"가 생긴다. 재료: `upgrade()` + 데이터 필드 하나.
  P3-E(메뉴 슬롯)의 축소 선행판 — E 를 나중에 얹어도 낭비가 없다

## 2. G25 — 시작 파크 + 물·지면 재질

**범위**
- `src/sim/startkit.ts`: 새 판 = **물려받은 작은 파크** — 풀 12칸(3×4, 표준 타일) · 입구 포장 3칸 · 화장실 1 · 데크체어 2 · 화분 2 · 야자수 2 · 자판기 1. 돈은 12,000G 그대로(PSS 도 첫 화면에 풀·자판기·의자가 있다 — Steam 스샷 4).
  ⚠ 봇·골든·튜토리얼 대사(「첫 풀을 파자」)가 전부 이 전제를 본다 — 인트로 비트를 「풀을 넓혀 보자」로 바꾼다.
- 물: `tile/pool` 3프레임을 **다이아몬드 반짝 무늬**(R6)로 다시 찍고, 코핑을 **흰 타일 띠 2텍셀 + 안쪽 진한 선**으로 (`drawCoping`). 풀 안 손님 발밑 물결 링.
- 지면: 모래·잔디·포장·실내를 **3D 프리렌더 타일**로(`tools/prerender` 에 `ground` 빌더 — 잔디 결·모래 알갱이·포장 이음을 툰+양자화로). 이음새 4방 검사(`seam`)를 부모에서 옮겨 온다.
- 실내: 실내 덩어리 외곽에 **유리 펜스 스프라이트**(벽 선 대신 2텍셀 유리 띠 + 기둥) · 문 1개 표식.
- 밀도 기본값: 토지 경계에 **나무 띠**(장식, 토지 밖 = 못 짓는 땅) — PSS 의 「파크 밖 나무·울타리」.

**검증**: 새 판 부팅 스크린샷의 물 비율 ≥ 12% (픽셀 검사 `?px=1`) · 시작 시설 7개 · 이음새 픽셀 0 · 봇 밴드 재측정 · 골든 재베이크.
**리스크**: 시작 킷이 밸런스를 밀어 올린다(1년차 현금) → `startMoney` 를 낮춰 상쇄.

## 3. G26 — 손님 생활 (가장 큰 체감)

**범위** (sim 상태기계 + 렌더)
1. **슬라이드 탑승**: `use` 상태를 `climb → ride → land` 로 나눈다. `ride` 는 활강로 칸을 `lane.length × 6 tick` 동안 따라가며 화면에서는 튜브 위 좌표(드롭 보간)를 탄다. 착수 칸에서 `land` → `splash-land` FX + 「Whoa!」 대사. 탑 위에 **대기 줄**(정원 초과 손님은 탑 아래 칸에 줄 선다, 최대 3).
2. **튜브 타기**: 수영 포즈에 튜브 스프라이트 6종(링 3색·백조·돌고래·바나나) — 선물(`gifts.json`) 소유에 따라 친구가 자기 튜브를 탄다, 일반 손님은 확률 30%. 물 위에서 **떠다니는 이동**(swim 상태 중 인접 풀 칸으로 2~3번 옮긴다).
3. **눕기·앉기**: 라운지 이용 = `lie` 포즈(데크체어 위 좌표) · 테이블 = `sit`. R3 규칙: **식당에서 사면 라운지를 찾아 앉고, 없으면 서서 먹고 나간다**(손님 위 「아이스크림 ×2」 팝 → 앉으면 음표 이모트).
4. **HP 아이콘**: HP < 30 → 머리 위 배터리 아이콘(빨강), 식당·라운지에서 회복하면 사라짐 (R4).
5. **체형 2종**: 어린이(12×22)·어른(18×32) — 나이로 결정(≤12 어린이). 노인 머리색(회색) 팔레트 추가.
6. 지불 팝: 라운지 대여 「600G」·입장료 — 이미 `money-pop` 있음, 위치를 손님 머리 위로.

**검증**: 슬라이드 탑승 경로가 활강로 칸을 전부 지나고 착수 칸에서 끝난다(단위) · 튜브 텍스처 6종 존재 · 라운지 없는 판에서 「서서 먹고 나간다」 분기 · HP<30 손님 위 아이콘(브라우저) · 프레임 p95 < 20ms @ 100명.
**리스크**: 상태기계 변경이 골든·밸런스를 흔든다(체류 시간↑ → 수입↓/↑) → 밴드로 잡는다.

## 4. G27 — 사건 밀도

**범위**
- `calendar.json` 7 → **24건**: R1 의 사장 선물 5건을 **정확한 시점**으로 · 연차 재료 지급(2~8년차 봄 1일) · 계절 연출(여름 주말 저녁 **불꽃놀이** FX · 겨울 **조명** 틴트 · 봄 꽃잎 · 가을 낙엽 파티클, 전부 FX 등록부) · 사장 방문 대사(연초) · 카이로봇 등장(★3).
- 친구 **첫 방문 대사**(71명분은 템플릿 6종 × 취향 삽입) · 소원 보상 **「받기」 연출**(메시지 탭에서 상자 열기 → 아이템 팝 + `wish` 징글).
- 인박스 → **알림함 창**(티커 배지, 읽음 처리) 정리.

**검증**: 달력 24건이 전부 발동(봇 128일) · 여름 주말 19시 불꽃 FX 카운트 > 0 · 첫 방문 대사 71명 전수(단위) · 모달 ≤1/분 유지.

## 5. G28 — 그림 완성도

**범위**
- 3D 모델 **디테일 패스**: 간판 글자판(2D 아이콘 합성은 있음) · 창문 안 상품 · 지붕 결(줄무늬 슬랩) · 의자 슬랫 · 나무 잎 덩어리 3톤. 약한 8종(카이로봇·머라이언·물폭탄·샤워·음수대·이글루·기둥·폭포) 먼저.
- **AI 아틀라스 파이프라인 재가동(9/7 이후)**: `sprite-gen gen --provider codex` → 우리 발자국 캔버스 계약(`footprintCanvas`)으로 잘라 `AtlasProvider` ID 교체. 게이트: 크기·앵커·팔레트(`--px-*` 43색 이내)·실루엣 IoU(3D 렌더 대비 ≥0.6). 부모 리포의 접지 게이트(`ground-geometry`)를 옮긴다.
- 손님: 머리 5 → 10종, 수영복 무늬(줄·물방울), 튜브 6종(G26 과 공유), 어린이 체형.
- 측정: 부모의 **도트 경계율** 자를 옮겨 레퍼런스(49%)와 대조.

**검증**: 갤러리 재검토(사람) · 아틀라스 게이트 통과율 · 경계율 45~55%.

**범위**

- 창 색조: 건설 파랑 · SNS 분홍 · 심사 보라(무대 조명 그라디언트 + 관중 띠) · 상점 초록 · 결산 금색.

**검증**: `check-ui` 대비·44px 전수 유지 · 서체 로드 검사(폰트 face 확인) · 라우트 스크린샷 11장 재판독.

# K38 — 지도 바깥을 땅으로 채운다 (배경 잇기)

## 문제 (실측)

사용자 스크린샷: 지도 **1시 방향**이 통짜 하늘색으로 비어 있다.

- 카메라 배경색은 `#7ab8d4` (`boot.ts:77`). 지도 다이아몬드 **바깥**은 아무것도 안 그리므로
  이 색이 그대로 보인다. 아이소라 다이아몬드의 **바운딩 박스 네 귀퉁이**가 비는데,
  화면이 넓을수록 크게 드러난다
- 배경 3겹(`mountain`·`ridge`·`farbank`)은 y −118~182 의 **가로 띠**다. 그 아래는 안 덮는다
- 배경 3겹은 **절차적 근사**(사인 합, `drawBackdrop`)다. 생성해 둔 산 아트
  (`assets/generated/backdrop/bg-mountain.png` 197×117, 가로 타일러블)를 게임이 안 쓴다

## 설계

### ① 주변 땅 — 바운딩 박스를 덮는 판 하나

다이아몬드의 **바운딩 박스**를 덮는 world-locked 타일스프라이트를 타일보다 **뒤**,
배경 띠보다 **앞**에 둔다. 타일이 있는 곳은 타일이 이기고, 없는 곳(귀퉁이)만 보인다.

```
깊이:  배경 띠(−994 ~ −965)  <  주변 땅(−900)  <  지면 타일(0+)
범위:  x −gh·STEP_X … gw·STEP_X   ·   y 0 … (gw+gh)·STEP_Y   (= 다이아몬드 bbox)
```

⚠ **설치는 구조적으로 불가능하다** — 격자 밖이라 sim 이 그 좌표를 모른다. 플래그로
막는 것이 아니라 존재하지 않는다 (사용자: "하지만 설치는 안되는").

⚠ `scrollFactor` 는 **1**이다. 배경 띠처럼 시차를 주면 공원 경계와 주변 땅이 미끄러져
"공원이 떠 있는" 것처럼 보인다 — 주변 땅은 공원과 **같은 거리**에 있다.

### ② 숲 캐노피 텍스처 — 생성해 둔 산 아트에서 뽑는다

`maps/raw-mountain.png` (1774×887) 아래쪽 숲 구역을 잘라 ÷8 NEAREST 로 줄이고
**가로·세로 양쪽에 랩 크로스페이드**를 걸어 타일러블로 만든다 (배경 파이프라인이 쓰던 수법).

산출물 `public/assets/backdrop/bg-canopy.png`. 생성 스크립트는 결정론적이고 커밋한다.

⚠ 공원 잔디보다 **어둡게** 둔다. 같은 밝기면 어디까지가 내 공원인지 안 읽힌다.

### ③ 먼 산은 실물 아트로

`bg-mountain.png` 를 `public/assets/backdrop/` 로 옮기고 `backdrop/mountain` 겹에 쓴다.
**로드 실패하면 지금의 절차적 근사로 폴백** — 아틀라스와 같은 방식이라 새 규칙이 아니다.

⚠ 계약 크기는 512×200 인데 아트는 197×117 이다. 계약을 바꾸지 말고 **씬이 실제 크기로**
타일링한다 — 계약을 바꾸면 절차적 폴백까지 같이 바뀐다.

### ④ 가장자리 전환 (①을 보고 판단)

다이아몬드 경계가 면도날 대각선이면 잘린 티가 난다. ①을 넣고 화면으로 보고,
필요하면 경계 바깥 한 줄에 나무 실루엣을 얹는다. **먼저 재고 정한다.**

## 하지 않을 것

- **격자 확장** — 96×72 를 늘리면 세이브 마이그레이션·성능·밸런스가 다 딸려 온다.
  비는 것은 격자가 작아서가 아니라 다이아몬드가 사각 화면을 못 채워서다
- **에셋 일괄 생산(Phase G)** — 사용자가 "오디오랑 에셋은 마지막"이라고 했다.
  배경 PNG 셋은 그 예외로 사용자가 직접 지목했다 (`raw-mo*` 를 넣어 달라)
- **주변 땅에 높이** — K37 의 단은 격자 안에서만 뜻이 있다

## 검증

1. **★ 다이아몬드 바깥이 하늘색이 아니다** — 넓은 화면에서 bbox 귀퉁이 픽셀이
   배경색(`#7ab8d4`)이 아니다. **음성 대조군**: 주변 땅을 끄면 그 픽셀이 배경색이다
2. **주변 땅이 타일을 안 가린다** — 공원 한가운데 픽셀은 그대로 잔디다
3. **캐노피가 타일러블이다** — 좌우·상하 이음선 대비가 문턱 안 (기존 이음새 QA 수법)
4. **아트가 없어도 부팅한다** — PNG 를 못 읽으면 절차적 폴백으로 뜬다 (콘솔 에러 0)
5. 회귀: `npm run verify` · `verify:kairo` · `seam` · `sim:kairo`

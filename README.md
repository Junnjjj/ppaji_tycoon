# 빠지 타이쿤 (Ppaji Tycoon)

> 가평 강변 리조트를 키우는 모바일 경영 시뮬레이션.
> 여름의 "빠지"(수상 구조물)가 주력이고, 사계절 운영한다.

**코드와 에셋 전부를 AI(Claude Code)로 제작하는 프로젝트.**
세로 모바일 최우선 — 웹/PWA 로 검증 후 Capacitor 로 앱 출시(프리미엄 유료).

## 핵심 루프 (30초)

```
[한 주 진행] → 압축 라이브 연출 3~5초 → [주간 결산]
     ▲              (카메라가 사건을 잡아줌)      │
     │                                        ├─ 병목·사고·발견 확인
     │                                        ├─ 이벤트/의뢰 카드 선택
     └────────── 구조물을 키우거나 붙임 ←─────────┘
```

- **잇는다** — 데크를 이어 붙여 빠지를 키우고, 건물을 증축한다 (연결식 구조물)
- **코스를 그린다** — 프리셋 + 터닝포인트 핸들로 수상 코스 설계 (장비 19종 × 형태 6종)
- **발견한다** — 인접 콤보 70종을 찾아 도감을 채운다
- **감상한다** — 최대 축소하면 내가 만든 리조트 전체가 살아 움직인다

## 현재 상태

**Phase 0~1 완료, Phase A(주 단위 루프) 착수 전.**

- ✅ 결정론 시뮬 코어 (시드 RNG · 고정 timestep · 손님 에이전트 · flow field 길찾기)
- ✅ Phaser 렌더러 (팬/핀치줌 카메라 · 지형 캐시 · 스프라이트 풀 · LOD)
- ✅ 에셋 추상화 (절차적 생성 → AI 픽셀아트 일괄 교체 경로)
- ✅ 세이브 v1 + 마이그레이션
- ✅ 헤드리스 시뮬레이터 (`npm run sim`) — 밸런싱을 숫자로
- ✅ 모바일 자동 검증 (`npm run verify:mobile`) — 아이폰 크기·터치 에뮬레이션
- 실측: 손님 1,200명 = 0.6ms/frame · 코스 실측 처리량 = 예측 ±20%

기획은 v1(자유 배치·실시간) → v3(주 단위·연결식) → **v4(압축 연출·경관·의뢰)** 로
적대적 검증을 거치며 수렴했다. 변경 이유는 전부 design.md 에 남아 있다.

## 개발

```bash
npm install
npm run dev            # 폰에서 보려면 출력된 Network URL
npm run verify         # typecheck + lint + test (커밋 전 필수)
npm run sim            # 헤드리스 시뮬 + 성능 리포트
npm run verify:mobile  # 모바일 실동작 자동 검증 (dev 서버 필요)
```

스택: **Phaser 3.90 + TypeScript 5.9 + Vite 7 + Capacitor** (버전 고정 이유는 CLAUDE.md)

## 아키텍처 불변식

1. `sim/` 은 Phaser·DOM 을 모른다 — Node 헤드리스로 그대로 돈다 (ESLint 강제)
2. `sim/` 은 결정론적이다 — `Math.random()`·`Date.now()` 금지, 시드 RNG 만
3. 시설·장비·콤보·연구는 코드가 아니라 `data/*.json` 이다

이 셋은 ESLint 규칙 + 회귀 테스트로 강제되며, 깨면 테스트가 실패한다.

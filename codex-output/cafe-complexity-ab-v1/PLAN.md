# 복잡한 시설 스킬 A/B 시험

카페3×2 검토 제안. 같은 개별 컨셉·atlas·brief와 같은 모델의 독립 새 컨텍스트2개, 각 후보1개/d0 보완최대2회. 기존 화장실 시험 전 스킬과 현재 최적화 스킬을 동결 제공. 기존 카페 모델/렌더/검토 결과는 제작자에게 제공하지 않는다.

비교: 주요 구조와 소품 가독성, 팔레트/재질, 네 방향 일관성, 저장본 재현성·크기·알파, 각 독립 제작자의 입력/캐시/출력/응답 수. 메인 검토/서빙 비용은 분리. 단일 시설 각1회는 전체 시설 절감률/동등 미술 품질의 인증이 아니다. 원본과 게임은 유지한다.

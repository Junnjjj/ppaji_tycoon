# 화장실 시설 스킬 독립 시험

매표소에서 사용자가 수용한 제작 수준을 화장실에 적용했다. 동결 스킬과 개별 원화·공유 atlas·2×2/H21 조건만 새 컨텍스트 제작자에게 제공했다. 기존 모델·렌더는 전달하지 않았다. 후보 하나, d0 추가 보완0회.

[컨셉·기존·후보 원격 비교](http://100.114.231.15:63021/run/review.html) — 동일 Tailscale 네트워크에서 접속. 실제 픽셀/고해상도와 네 방향 전환 가능. 영구 서버는 아니다.

새 후보는 짙은 평지붕/파라펫과 판넬, 크림 벽, 청록 타일 줄눈, 주황빛 적색/파랑 문, 상부 창과 우측 환기구를 유지한다. 기존보다 주요 구조가 원화에 가까워졌다. 질감은 더 매끈하고 규칙적이며 문 색은 더 밝다. 작은 픽토그램의 성별 구분은 실제 크기에서 인증하지 않는다. 색 패치 측정에는 조명/투영 차이가 포함되므로 색상 일치 판정이 아니다.

설치 바닥2×2는 같지만 독립 새 형상이다. 몸체1.86×1.86(기존1.8×1.8), 지붕2.08×2.08(기존1.96×1.96), 높이2.065(기존1.9746) tile. 숨겨진 뒤/왼쪽 면은 닫힌 벽 제안이다.

검증:
- 독립 Blender 재열기 및 재렌더8장 RGBA 완전 일치, 잘림0.
- 고정 카메라, 동일 루트131메시, 문2/정면상부창4/우측창2/우측환기구1 확인.
- 투영 양성대조PASS/의도적 음성대조FAIL, d1–d3 선검출PASS. d0 수직선 검출87.75도 WARN은 저장 카메라 및 분석상 수직90도와 구분해 보존. 대조 검사를 모델 제작 후 실행한 절차 차이가 있다.
- 고정 입력24파일/원본 및 라이브 보호44파일 해시 유지. 비교16장 알파가 공통 표시영역 안에 들어간다.
- 원격 페이지 및 이미지18파일 HTTP 내용 일치. 브라우저16방향/배율/해상도 조합 확인,390px 화면 가로 넘침 없음.

후보: output/toilet.blend, output/color-d0.png~d3.png, output/native-d0.png~d3.png. 근거: output/manifest.json, output/qa.md, preservation-check.json, browser-review.json.

화장실 시험용 스킬 수정 없이 다른 재질 시설을 만든 증거다. 전 시설 재현성/사용자 미술 승인을 의미하지 않는다. 기존 맵/NPC/라이브 유지. 화장실 외형 평가 대기.

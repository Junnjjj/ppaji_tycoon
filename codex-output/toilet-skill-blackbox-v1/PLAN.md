# 화장실 독립 제작 시험

매표소에서 사용자가 수용한 제작 방식을 다른 재질의 시설로 검증한다. 현재 스킬을 동결한 독립 컨텍스트에 원화·재질 atlas·2×2/H21 조건만 제공했다. 기존 모델과 렌더는 비교 담당자만 읽는다.

- 원화: 기존 화장실 패키지에 연결된 개별 참조. 파일명으로 별도 미술 승인을 추정하지 않는다.
- 새 후보 하나, 필요할 때 d0 보완 최대 2회. 작은 픽토그램의 완전 복제보다 색/재질/주요 구조와 실제 표시 가독성을 우선한다.
- 네 물리 회전과 두 렌더 크기, 저장본 독립 재렌더, 원본·입력 보존을 확인한다.
- 동일 카메라/배율로 컨셉·기존·후보를 원격 비교한다. 기존 맵/라이브 채택은 포함하지 않는다.

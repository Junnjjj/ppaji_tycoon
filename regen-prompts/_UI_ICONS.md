빠지 타이쿤 저장소에서 **UI 아이콘 44장과 사건 배경 9장**을 생성해 줘.
화면의 표식이 지금 전부 이모지 글리프라 기기마다 다른 그림이 나오고 게임 아트와 재질이 안 맞는다.

## 먼저 읽을 것

- `docs/asset-ui-icons-order.md` — 아이콘 44장 (§1 무엇을 → §2 어떻게 → §3 판정 → **§4 하면 안 되는 것**)
- `docs/asset-event-art-order.md` — 사건 배경 9장. **§2 의 「배경만 그린다」가 이 작업의 핵심 규칙이다**

§4 를 안 읽으면 이미 두 번 실패한 길을 그대로 반복하게 된다.

## 규격

| | 크기 | 배경 | 넣는 곳 |
|---|---|---|---|
| 아이콘 44 | 48×48 | **투명** | `public/assets/ui-icons/<id>.png` |
| 배경 9 | 480×160 | 불투명 가능 | `public/assets/event-art/<id>.png` |

파일명은 계약 id 에서 접두어를 뗀 것 — `ui/course` → `course.png`, `event/crowd` → `crowd.png`.

## 합격 기준은 우리 게이트가 정한다

```bash
npx tsx tools/check-ui-icons.ts            # 반입분 판정
npx tsx tools/check-ui-icons.ts --selftest # 자가 실제로 재는지 (6/6)
```

크기 · 투명 배경 · **팔레트 이탈 2% 이하** · **크림(#f0d5a4) 위 대비 3:1** · 계약 밖 파일 0.
넘기기 전에 직접 돌려 보고 통과분만 보내도 된다.

⚠ **100% 를 요구하지 않는다.** 떨어진 장은 버리고 그 id 만 글리프/자리표시로 떨어진다 —
화면은 안 깨진다 (Phase G `HybridProvider` 와 같은 규칙).

## 가장 자주 걸리는 것 둘

1. **크림 위 대비** — 크림 팔레트 위에 크림색 아이콘을 그리면 사람 눈에도 안 보인다.
   잉크는 따뜻한 진갈색(`#4a2f14` 언저리)
2. **한 시트에 여러 장** — 4-up 이면 해상도가 1/4 로 떨어져 색이 샌다 (실측: 빨강이 주황으로).
   한 번에 한 장, 크게 뽑고 줄일 것

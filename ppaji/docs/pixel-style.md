# 워터파크 스토리 도트 스타일 계약 (G14)

레퍼런스는 `../art-reference/competitor/pool-slide-story-park.jpg` (실제 Pool Slide Story 화면) 하나다.
**목표는 그 화면에 우리 스프라이트를 놓아도 안 튀는 것**이다. 예쁜 한 장이 아니라 「같은 게임」으로 보이는 것.

## 실측 (레퍼런스 타일 폭 40px 기준 → 우리 32텍셀 타일로 환산)

| 대상 | 레퍼런스 | 우리 계약 |
|---|---|---|
| 지면 타일 | 40×20 (2:1) | **32×16** |
| 손님 | 폭 0.55타일 · 키 1.0타일 | **18×32** 캔버스, 앵커 (9, 30) — 2.5등신, 머리 12, 눈 2텍셀(세로) |
| 1×1 시설 | 타일을 **꽉 채움**, 높이 0.8~1.2타일폭 | 캔버스 32×(16+bodyH) — 폭 30~32 다 쓴다. bodyH: 편의 28 · 라운지 16 · 식당 34 · 놀이 26 · 슬라이드 44 · 장식 30 |
| 2×2 시설 | 2타일 폭 | 64×(32+bodyH) |
| 1×2 시설 | | 48×(24+bodyH) |

## 그리는 규칙

1. **입체는 3면이다** — 윗면(밝은 톤 `2`) · 왼쪽 앞면(기본 `1`) · 오른쪽 앞면(어두운 톤 `3`). 2:1 다이메트릭이라 윗면 다이아몬드의 변은 「가로 2 : 세로 1」 계단이다. 정면 사각형 하나로 그리지 말 것 — 그게 「대충」의 정체다.
2. **외곽선은 1텍셀 남색 `k`** 로 실루엣 전체를 감싼다. 안쪽 면 경계도 `k` 로 가른다. 옅은 색끼리 붙이면 뭉개진다.
3. **명암 3톤 + 하이라이트** — 윗면·왼쪽 위 모서리에 흰 `w` 1텍셀 줄. 어두운 톤은 기호 문자(`!@#$%^&~=`) 또는 슬롯 `3`.
4. **바닥에 앉힌다** — 물체의 밑변은 발자국 다이아몬드 위에 있고, 아래 두 변을 따라 어두운 톤이 1~2줄 보인다 (받침·그림자 띠).
5. **한 물체에 소재 셋** — 예: 데크체어 = 흰 슬랫 + 파란 천 + 갈색 다리. 단색 덩어리는 안 된다.
6. **간판·소품이 정체를 말한다** — 식당은 차양 줄무늬 + 카운터 + 음식 아이콘, 편의는 문·표지, 놀이는 물(`c/C/^`)이 보인다.
7. **글자를 그리지 않는다** (이름 라벨은 절차 단계의 흔적이었다).
8. 색은 전부 `--px-*` 토큰(`src/assets/draw/pix.ts` 의 문자표). 새 색이 필요하면 토큰을 더한다 — TS 에 hex 금지(S1 게이트).
9. 손님 포즈: idle 1 · walk 2 · swim 2. 걷기는 다리 교차 + 팔 흔들림. 수영은 튜브(수영복 보색) 안에 상반신.

## 검증

- `npm run gallery` → `tmp-shots/gallery.png` 를 **눈으로 본다**. 레퍼런스 크롭(스크래치 `px/ref/*.png`)과 나란히 놓고 크기·밀도·톤 수를 대조한다.
- `npx tsc --noEmit && npx eslint src && node tools/check-ui.mjs` 초록.
- 캔버스 밖으로 넘치는 줄은 `blit` 가 조용히 자른다 — 템플릿 폭 ≤ 캔버스 폭, 높이 ≤ 캔버스 높이를 지킬 것.

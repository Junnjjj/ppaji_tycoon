> 자동 게이트(`cd ppaji && npm run gate -- p20`: typecheck · lint · vitest 335 · 봇 밴드 23 · 브라우저 184절)는 전부 통과했다.
> 아래는 **에뮬레이션이 못 잡는 것**만이다 — 진짜 폰, 진짜 손가락, 진짜 30분.
> 「자동 통과를 사람 승인으로 보고하지 않는다」 — 한 줄도 ⬜ 인 채로는 「완료」라고 쓰지 않는다.
> (2026-09-05 까지 이 파일은 워터파크 목록의 복제본이었다 — 빠지 축 기준으로 다시 썼다.)

## 준비

```bash
cd ppaji && npm run dev              # http://<LAN IP>:5187 — 폰에서 연다
npx tsx tools/serve-dist.mjs 5189    # 또는 빌드본 — http://100.114.231.15:5189/ (no-store)
npm run replay -- --stage late       # 참고용 스크린샷 (판정 아님) → tmp-shots/replay/late/*.png (저녁 컷 포함)
```

- 기기: **393×852 @3x 급** 세로. 에뮬레이션 아님. 매번 **새 판**(`?fresh=1` 또는 MENU → 새 게임)에서 시작한다
- 시간 감기는 없다(하루 210초). 저녁·숙박 항목은 **한 판을 폐장까지** 보고 판정한다

# 빠지 스토리 — 가평 강변 빠지 경영 (워터파크 스토리 클론 위에 다시 세운 빠지 타이쿤)

빠지 타이쿤 리포의 **독립 하위 프로젝트**다 (자체 `package.json`). `waterpark/`(카이로소프트 *Pool Slide Story* 클론)를
**통째로 복제**한 뒤(D1) 한국 강변 수상레저 「빠지」로 다시 썼다 — 시간·SNS·인증·상점·달력의 워터파크 루프는 그대로,
물은 **강 위에 부표로 친 수역**(D3), 빠지 타이쿤에서 **견인 코스**(선착장·프리셋 6·핸들·기구 30)만 그대로 옮겼다(D4).

계획·결정·이력의 정본: **`../docs/plan-ppaji-story.md`** (§0 D1~D26 · §6 P0~P18 · §7 이력 · §8 미결). 에셋 계약: `../docs/ppaji-asset-contract.md`.

```bash
npm i
npm run dev                # http://localhost:5187  (?debug=1 → window.__pj · ?px=1 픽셀 검사 · ?fresh=1 저장 무시 · ?tut=0)
npm run gate -- p0         # typecheck + lint + vitest + 정적 UI(+selftest) + 봇 밴드 + 브라우저 실터치 (pN = 100+N, 승계 G0~G57 절 포함)
npm run gate -- p13        # 전 goal 누적 게이트
npm run bot -- --seeds 8 --days 128 --bands          # 헤드리스 봇 밴드 18 (Phaser 없이 Node — 불변식 1 실증)
npm run bot -- --seeds 24 --days 128 --persona all   # 성향 5종(balanced·pool·restaurant·cert·course) 비교표
npm run replay -- --stage early|late                 # 재플레이 두 벌 스크린샷 (dev 서버 필요, 판정 없음) → tmp-shots/replay/
npx tsx tools/serve-dist.mjs 5189                    # 빌드(dist) 정적 서빙 — 폰에서 http://<LAN IP>:5189
```

## 무엇이 다른가 (워터파크 → 빠지)
| 축 | 빠지 스토리 |
|---|---|
| 물 | 입구가 위, 지도 아래 22줄이 강(레거시 방향, D21). **수영 구역 = 데크로 둘러싼 물이 자동으로 수역**(D22, `syncEnclosedWater`) — 부표를 손으로 치는 붓은 없다. 수면 허가는 랭크마다 +3줄(D23, `waterRowMax`) |
| 코스 | `src/sim/course/` — 선착장 앵커 · 프리셋 6 · 핸들 드래그 · 4초 시험 운행 · 승선 = 선착장 이용(요금·만족). **코스는 부표·데크 밖의 트인 강만** 지난다(수영 손님과 보트를 안 섞는다) |
| 기구 공방 | `src/sim/workshop.ts` — 요리 개발 문법(`CookingStore` 제네릭) 그대로: 부품 41 → 기구 33(승계 19 + 공방 11 + 실패작 3), Lv → 스릴 소급 |
| 손님 | 출신지 10(가평 읍내 · 대학가 MT · 가족 캠핑 · 커플 · 회사 워크숍 · 군부대 휴가 · 펜션 단체 · 낚시 동호회 · 외국인 관광 · 유튜버) + 출신지 취향 · 친구 71 · 소원 213 |
| 인증 | 24종 8계열(물놀이·경관·핫플·사철·맛집·스릴·안전·청결) · 심사위원 군청 공무원·해경·유튜버 · **편향 0**(D15) |
| 요리 | 레시피 180 · 재료 70 · 식당 26 한국화 · 궁합 26 |
| 직원 | 직원 창 없음 — **시설별 알바 슬롯**(D14): 60G/일 유지비 합산, 매점·선착장·편의 효과, 청결은 게임이 소유 |
| 길·뷰·콤보 | P16(D24): 손님은 **길·데크·실내만** 걷는다(수역 독 「길」 탭 20G/칸 · 봇·킷·API 는 자동 길). 정면 4줄에 강이 보이면 뷰 1~4 → 평상·식당·놀이 인기 +10%×뷰. `combos.json` 인접 콤보 40(매점 앞 평상 …) → 만족·판매가·인기, 수집 「콤보 N/40」 |
| 팀 자리·패키지 | P17(D25): 버스 하나 = 팀 하나(`teamId`), 유료 평상은 팀 열쇠(`rentKey`)로 같이 쓴다. 자리 값 = 1+그늘(`shade`)+뷰+매점 5칸 → 평상 만족 배수. 자리를 잡으면 `packages.json` 3종(고기·기구·수영) 중 취향 큰 것을 미리 산다(`stats.pkg`). 자리 없으면 「자리가 없네…」 |
| 1박·밤 | P18(D26): 18시부터 저녁(헤더 「· 저녁」·밤 틴트·조명·불멍 FX). `lodging` 6종을 팀 손님이 자리로 잡으면 1박 요금(`stats.lodging`)을 내고 폐장 뒤 남아(`stays`, `stats.overnight`) 아침에 이어서 논다. 하루 1,680 tick·20시 폐장은 그대로 |
| 높이 | `Grid.levels` 0~3 — 강 계곡 BFS(1-Lipschitz)로 테라스, 물은 0(D17) |
| 돈 | G 그대로(D13) — 기구값 ×0.01 · 승선 요금 35~140G |

지형 `64×48`, 타일 32×16 텍셀, 카메라 줌 1 + 정수 업스케일(D9). 색은 `src/ui/style.css` 토큰만(`tools/check-ui.mjs` S1~S9 가 지킨다).

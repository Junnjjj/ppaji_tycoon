# 워터파크 스토리 클론 — 실기 확인 목록 (G32)

> 자동 게이트(`npm run gate -- g32`: typecheck · lint · vitest 207 · 봇 밴드 8/8 · 브라우저 107절)는 전부 통과했다.
> 아래는 **에뮬레이션이 못 잡는 것**만이다 — 진짜 폰, 진짜 손가락, 진짜 스피커.
> 「자동 통과를 사람 승인으로 보고하지 않는다」 — 한 줄도 ⬜ 인 채로는 「완료」라고 쓰지 않는다.

## 준비

```bash
cd waterpark && npm run dev        # 출력된 Network URL 을 폰에서 연다 (LAN)
node tools/serve-dist.mjs 5178     # 또는 빌드본 (no-store) — 메뉴 제목의 빌드 표식으로 새 번들인지 확인
# 오류가 보이면 URL 에 ?diag=1 — 콘솔 없는 폰에서 부팅 오류를 화면 위에 띄운다 (G40)
# 시뮬레이터 선검사: orca emulator attach "iPhone 17e" → xcrun simctl openurl booted http://localhost:5179/?diag=1
```

- 기기: **393×852 @3x 급**(아이폰 12~15) 세로. 에뮬레이션 아님
- 매번 **새 판**(`MENU → 새 게임 (저장 삭제)`)에서 시작한다 — 잔해 위에서 재면 원인을 모른다

## P0-5. **"만족"이 네 화면에서 네 이름 · 네 눈금**이다

같은 한 값(퇴장 만족도 이동평균 = 평판)이 이렇게 보인다:

| 화면 | 표기 | 눈금 | 경로 |
|---|---|---|---|
| 헤더 (상시) | `😊 0%` | **백분율** | `src/ui/kairo-hud.ts:395` |
| 결산 KPI | `퇴장 만족 66` | 단위 없음 | `src/ui/kairo-report.ts:113` |
| 메뉴 장기 목표 | `만족도 0/55` | 55 만점? | `src/main.ts:2850` |
| 심사 조건표 | `퇴장 만족도 0 / 55` | 55 | `src/ui/kairo-exam.ts:42` |
| 심사 잠금 사유 | `평판 55 필요 · 지금 0` | 55 | `src/ui/kairo-exam.ts:135` |
| 인증 목록 | `만족 0/80` · `만족 0/88` | 80·88 | `src/sim/kairo/progress.ts` (`facilityTotalAndSat`) |
| 가격 화면 | `만족도 +3` | 델타 | `src/ui/kairo-staff.ts:299` |

**플레이어가 못 푸는 질문**: 헤더의 `0%` 와 목표의 `0/55` 가 같은 값인가? 66 은 몇 %인가?
`평판` 은 `만족도` 와 다른 것인가? (같다 — `src/main.ts:1633` 주석이 그렇게 적어 두었다.)

**제안 — 이름 하나 · 눈금 하나로 통일**

```
정본 이름:  평판        (등급·심사·인증이 쓰는 값 = 퇴장 만족도의 이동평균)
정본 눈금:  0~100 정수, % 아님

헤더    😊 0%        →  ⭐평판 0        (등급 별과 겹치면 😊 유지, 단 % 를 뗀다: 😊 0)
결산    퇴장 만족 66 →  평판 66  (이번 주 퇴장 만족)
목표    만족도 0/55  →  평판 0/55
심사    퇴장 만족도  →  평판              · 잠금 사유도 `평판 55 필요 · 지금 0` 그대로
인증    만족 0/80    →  평판 0/80
가격    만족도 +3    →  평판 +3 (이번 주)
```

`퇴장 만족도` 라는 정확한 말은 **결산의 부제 한 줄에만** 남긴다
(`평판 66 — 손님이 나갈 때의 만족 평균입니다`). 그 자리가 이 개념을 가르치기에 가장 좋다.

## P1-10. 인증 상세가 **주어 없는 숫자쌍**이다

**실측** (메뉴 하단 인증 목록):


`detail` 에 **수치와 단위만** 담는다 (`needSupply` → `` `${cur} / ${goal}개` ``,
`facilityCount` → `` `${cur} / ${goal}개` ``). 주어는 소비자가 붙이는 계약이다:

- **심사 화면은 붙인다** — `src/ui/kairo-exam.ts:40` 이 조건 종류별 한글 이름을
  행 라벨로 그린다 (`위생 시설  0 / 3개`)
- **인증 목록은 안 붙인다** — `src/main.ts:3433` 이
  `` s.reqs.map((r) => `${r.done ? '✓' : '·'} ${r.detail}`).join('  ') `` 로
  라벨 없이 이어 붙인다

즉 같은 함수를 한 곳은 라벨과 함께, 한 곳은 라벨 없이 쓴다.

```
[before] 🏅 수상레저 인증   · 1 / 3개  · 5 / 8개 → 정원 +6 · 허가 +40
[after]  🏅 수상레저 인증
         · 선착장 1/3   · 물 위 시설 5/8      →  동시 입장 +6 · 수면 허가 +40칸
```

같은 김에 두 보상어도 고친다 — `정원` 은 시설 정원과 헷갈리고(건설 카드가
`정원 4` 로 쓴다), `허가` 는 이 화면에 처음 나오는 낱말이다:
`정원 +6` → **`동시 입장 +6명`**, `허가 +40` → **`수면 허가 +40칸`**
(`main.ts:2189` 는 이미 `수면 허가 +N칸` 으로 쓴다 — 두 곳이 다르다).

또 `아직 한 주를 안 돌렸다` (`progress.ts` `maxTurnedAway`)는 목록 안에서 유일한
반말 서술문이다 → `첫 결산 뒤 판정` 으로.
